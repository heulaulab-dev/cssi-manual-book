# Konfigurasi TI

Halaman Konfigurasi TI memungkinkan pengguna berwenang mengelola konfigurasi daftar periksa untuk Divisi TI. Anda dapat membuat, memberi nama ulang, dan menghapus tugas, bagian, dan item daftar periksa yang muncul di halaman Daftar Periksa Hari Ini.

- **Perluas Semua** — Klik untuk memperluas semua bagian tugas dan bagian

## Membuat tugas baru

1. Klik tombol **Tugas Baru** (atau tombol **Buat Tugas** di status kosong)
2. Masukkan nama tugas di bidang **Tugas**
3. Klik **Buat Tugas**
4. Tugas baru muncul di daftar tugas

## Bagian tugas

Tugas ditampilkan sebagai bagian yang dapat dilipat. Setiap tugas menampilkan:

- **Nama tugas**
- **Jumlah bagian** — Jumlah bagian di dalam tugas
- **Jumlah item** — Jumlah item daftar periksa di seluruh bagian

### Memberi nama ulang tugas

1. Klik tombol **Ubah Nama** (ikon pensil) di baris tugas
2. Edit nama tugas di editor inline
3. Tekan **Enter** atau klik **Simpan** untuk mengonfirmasi
4. Tekan **Escape** atau klik **Batal** untuk membatalkan

### Menghapus tugas

1. Klik tombol **Hapus** (ikon tempat sampah) di baris tugas
2. Dialog konfirmasi muncul menjelaskan konsekuensinya
3. Klik **Hapus** untuk mengonfirmasi, atau **Batal** untuk membatalkan

<Callout type="warning">
  Menghapus tugas akan menghapus semua bagian dan item daftar periksa nya. Pengiriman yang ada
  yang merujuk ke tugas mungkin terpengaruh.
</Callout>

## Bagian bagian

Di dalam setiap tugas, bagian ditampilkan sebagai bagian nested yang dapat dilipat. Setiap bagian menampilkan:

- **Nama bagian**
- **Jumlah item daftar periksa**

### Menambahkan bagian

1. Perluas bagian tugas
2. Klik formulir inline **Tambah Bagian** di bagian bawah tugas yang diperluas
3. Masukkan nama bagian di bidang **Nama bagian**
4. Klik **Tambah Bagian**

### Memberi nama ulang bagian

1. Klik tombol **Ubah Nama** (ikon pensil) di baris bagian
2. Edit nama bagian di editor inline
3. Tekan **Enter** atau klik **Simpan** untuk mengonfirmasi

### Menghapus bagian

1. Klik tombol **Hapus** (ikon tempat sampah) di baris bagian
2. Dialog konfirmasi muncul
3. Klik **Hapus** untuk mengonfirmasi, atau **Batal** untuk membatalkan

## Tabel item daftar periksa

Di dalam setiap bagian yang diperluas, item daftar periksa ditampilkan dalam tabel:

| Kolom | Deskripsi |
|---|---|
| **#** | Nomor item berurutan |
| **Item Daftar Periksa** | Nama item daftar periksa |
| **Urutan** | Nomor urutan pengurutan |
| **Tindakan** | Tombol Ubah Nama dan Hapus |

### Menambahkan item daftar periksa

1. Perluas bagian bagian
2. Gunakan formulir **Tambah Item** di bagian bawah bagian yang diperluas
3. Masukkan nama item di bidang **Item daftar periksa**
4. Klik **Tambah Item**

### Memberi nama ulang item daftar periksa

1. Klik tombol **Ubah Nama** (ikon pensil) di baris item
2. Edit nama item di editor inline
3. Tekan **Enter** atau klik **Simpan** untuk mengonfirmasi

### Menghapus item daftar periksa

1. Klik tombol **Hapus** (ikon tempat sampah) di baris item
2. Dialog konfirmasi muncul
3. Klik **Hapus** untuk mengonfirmasi, atau **Batal** untuk membatalkan

## Status kosong

Jika tidak ada tugas yang dikonfigurasiYet, Anda akan melihat status kosong dengan tombol **Tugas Baru** untuk memulai. Jika pencarian Anda tidak cocok dengan konfigurasi apa pun, Anda akan melihat pesan yang menyarankan Anda mencoba pencarian berbeda.

<Callout type="info">
  Perubahan yang dibuat di Konfigurasi TI berlaku secara langsung. Tugas dan
  item yang baru dibuat akan muncul di halaman Daftar Periksa Hari Ini untuk tanggal
  operasional yang relevan.
</Callout>

<Callout type="info">
  Anda memerlukan izin Konfigurasi TI untuk mengakses halaman ini. Hubungi
  administrator Anda jika Anda tidak melihat halaman Konfigurasi TI di bilah sisi.
</Callout>
