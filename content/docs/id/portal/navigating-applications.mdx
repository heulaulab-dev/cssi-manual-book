# Menavigasi Aplikasi

Portal adalah titik awal untuk CSSI, sementara alur kerja detail terjadi di aplikasi terkait. Panduan ini menjelaskan cara berpindah antara Portal dan aplikasi lainnya.

## Menggunakan navigasi aplikasi atas

Bilah navigasi atas di Portal memungkinkan Anda beralih antar aplikasi. Ketika Anda berada di Portal, Anda dapat mengklik nama aplikasi lain untuk membukanya di tab baru.

Aplikasi saat ini yang ditampilkan:

- Portal
- CRM
- Intranet
- FLOWRA
- ITQM
- Daily Operation

## Menggunakan bagian Aplikasi

Bagian Aplikasi di bagian bawah Dashboard menyediakan kartu untuk setiap aplikasi CSSI yang tersedia. Setiap kartu menampilkan:

- Nama aplikasi
- Deskripsi singkat
- Tombol **Buka `Nama Aplikasi`**

Klik tombol **Buka** untuk meluncurkan aplikasi.

## Menggunakan aksi widget dasbor

Beberapa widget dasbor menyediakan tombol aksi yang membawa Anda ke alur kerja terkait di aplikasi lain:

| Widget | Aksi | Ke mana ini mengarah |
|---|---|---|
| Pengumuman Intranet | **Lihat semua pengumuman intranet** | Aplikasi Intranet |
| Pengembangan | **Tambah permintaan pengembangan** / **Lihat semua pengembangan** | Aplikasi ITQM |
| Daftar Periksa Harian | **Tambah daftar periksa harian** / **Lihat semua daftar periksa** | Aplikasi Daily Operation |
| Saham | **Buka saham** / **Lihat semua saham** | Aplikasi CRM |
| Peringkat | **Buka peringkat P/L** / **Buka peringkat perdagangan** | Aplikasi CRM |

## Menggunakan bel notifikasi

Klik ikon **bel notifikasi** di pojok kanan atas halaman untuk melihat notifikasi Anda. Dari sana, Anda dapat:

- Filter notifikasi berdasarkan kategori (Semua, Keamanan, Lingkungan, Perangkat)
- Tandai notifikasi sebagai sudah dibaca
- Navigasi ke sumber setiap notifikasi

## Menggunakan pengaturan Akun

Klik pada **ikon atau nama profil** Anda di pojok kanan atas untuk mengakses:

- **Akun** — Kelola profil, pengaturan keamanan, dan preferensi Anda
- **Keluar** — Log out dari Portal
