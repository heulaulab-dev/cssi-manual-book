# Pengaturan Akun

Halaman pengaturan Akun Anda memungkinkan Anda mengelola informasi profil, kredensial keamanan, sesi aktif, dan preferensi aplikasi. Akses dengan mengklik **ikon atau nama profil** Anda di pojok kanan atas halaman, lalu memilih **Akun**.

## Profil

Tab Profil memungkinkan Anda mengelola informasi pribadi Anda.

### Mengedit profil Anda

1. Klik tombol **Edit Profil**
2. Perbarui **Nama Depan**, **Nama Belakang**, atau **Email Utama** sesuai kebutuhan
3. Klik **Simpan Perubahan** untuk menerapkan pembaruan, atau **Batal** untuk membatalkannya

### Nama pengguna Anda

Nama pengguna ditampilkan untuk referensi tetapi tidak dapat diubah melalui antarmuka ini. Nama pengguna dikelola oleh administrator Anda.

## Keamanan

Tab Keamanan memungkinkan Anda mengubah kata sandi.

### Mengubah kata sandi Anda

1. Masukkan **Kata Sandi Saat Ini**
2. Masukkan **Kata Sandi Baru** (minimal 8 karakter)
3. Masukkan kembali kata sandi baru di **Konfirmasi Kata Sandi Baru** untuk memverifikasinya cocok
4. Klik **Ubah Kata Sandi**

## Sesi

Tab Sesi menampilkan di mana Anda masuk dan memungkinkan Anda mengelola sesi aktif.

### Sesi saat ini

Sesi Anda saat ini selalu ditampilkan di bagian atas. Ini menampilkan:

- **Perangkat** — Perangkat yang Anda gunakan
- **Peramban** — Peramban web Anda
- **Alamat IP** — Alamat jaringan Anda
- **Aktif** — Berapa lama sesi Anda saat ini telah dibuka

### Sesi lain

Jika Anda masuk dari perangkat lain, sesi tersebut akan muncul di bawah **Sesi Lainnya**. Untuk setiap sesi, Anda dapat melihat:

- **Perangkat** — Nama perangkat
- **Alamat IP** — Alamat jaringan

### Mengelola sesi

- Klik **Cabut** di sebelah sesi lain untuk keluar dari perangkat tersebut
- Klik **Keluar dari semua lainnya** untuk mencabut semua sesi kecuali sesi Anda saat ini

Ini berguna jika Anda menduga akun Anda mungkin diakses dari perangkat yang tidak dikenal.

## Preferensi

Tab Preferensi memungkinkan Anda menyesuaikan pengalaman Portal Anda.

### Mode tema

Pilih bagaimana tampilan Dasbor:

| Tema | Deskripsi |
|---|---|
| **Gelap** | Latar belakang gelap dengan teks terang |
| **Terang** | Latar belakang terang dengan teks gelap |
| **Gelap Klasik** | Tema gelap dengan kontras tinggi |
| **Sistem** | Otomatis menyesuaikan dengan pengaturan tema komputer Anda |

### Perilaku bilah sisi

Pilih bagaimana bilah sisi kiri berperilaku:

| Perilaku | Deskripsi |
|---|---|
| **Diperluas** | Bilah sisi selalu terbuka |
| **Dicolaps** | Bilah sisi diminimalkan; klik untuk memperluasnya |
| **Perluas saat hover** | Bilah sisi memperluas ketika Anda menggerakkan mouse di dekat tepinya |

### Preferensi notifikasi

Kontrol jenis notifikasi mana yang Anda terima:

| Pengaturan | Deskripsi |
|---|---|
| **Notifikasi Email** | Terima notifikasi melalui email |
| **Notifikasi Push** | Terima notifikasi push peramban |
| **Notifikasi SMS** | Terima notifikasi melalui pesan teks |

Aktifkan atau nonaktifkan setiap pengaturan menggunakan sakelar di sebelahnya.
