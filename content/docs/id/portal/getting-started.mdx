## Setup pertama kali

Jika ini adalah pertama kalinya Anda masuk, Anda mungkin diminta untuk mengubah kata sandi. Ini adalah tindakan keamanan untuk memastikan akun Anda terlindungi.

<Steps>
  <Step>

### Langkah 1 — Ubah kata sandi Anda

Ketika Anda masuk untuk pertama kalinya, Anda akan diarahkan ke halaman reset kata sandi. Masukkan kata sandi sementara Anda, pilih kata sandi baru yang aman (minimal 8 karakter), dan konfirmasi.

> **Placeholder screenshot**
>
> Add screenshot: Formulir reset kata sandi pertama kali.

  </Step>
  <Step>

### Langkah 2 — Lanjutkan ke dashboard Anda

Setelah berhasil mengubah kata sandi, Anda akan diarahkan kembali ke Portal Dashboard.

  </Step>
</Steps>

## Apa yang harus dilakukan selanjutnya

- Jelajahi widget **Dashboard** Anda untuk memahami informasi apa yang tersedia untuk Anda
- Periksa bagian **Aplikasi** di bagian bawah dashboard untuk mengakses aplikasi CSSI lainnya
- Klik pada nama Anda di pojok kanan atas untuk mengakses **Pengaturan Akun**
- Klik ikon **bel** untuk melihat notifikasi Anda

<Callout type="info">
  Dashboard Anda mungkin terlihat berbeda dari dashboard pengguna lain karena beberapa
  widget hanya tersedia untuk divisi dan peran tertentu.
</Callout>

<Callout type="info">
  Jika Anda tidak dapat mengakses aplikasi atau fitur tertentu, silakan hubungi
  administrator Anda untuk meminta izin yang sesuai.
</Callout>
