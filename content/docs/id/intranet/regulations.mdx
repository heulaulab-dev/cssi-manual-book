# Regulasi

Bagian Regulasi mengorganisasi dokumen regulasi perusahaan ke dalam tiga kategori: **Kepatuhan**, **HRD**, dan **Legal**. Setiap kategori memiliki daftar dokumen sendiri dengan versi, subsection, dan lampiran.

## Kategori

Regulasi diorganisasi menjadi tiga kategori, yang dapat diakses dari bilah sisi di bawah **Regulasi**:

| Kategori | Deskripsi |
|---|---|
| **Kepatuhan** | Dokumen dan kebijakan regulasi kepatuhan |
| **HRD** | Regulasi dan panduan departemen sumber daya manusia |
| **Legal** | Dokumen legal dan regulasi |

Klik kategori di bilah sisi untuk melihat daftar dokumennya.

## Menelusuri regulasi

Setiap halaman kategori menampilkan regulasi dalam tabel yang dapat diurutkan. Setiap entri menampilkan:

- **Judul** — Nama dokumen regulasi (klik untuk melihat detail)
- **Divisi** — Divisi organisasi yang menjadi milik regulasi
- **Penting** — Badge merah **Penting** jika regulasi ditandai penting
- **Periode Efektif** — Rentang tanggal ketika regulasi berlaku
- **Diperbarui** — Kapan regulasi terakhir diperbarui
- **Tindakan** — Tombol Lihat, Edit, atau Hapus

## Mencari dan memfilter regulasi

Gunakan bilah pencarian di bagian atas tabel untuk menemukan regulasi berdasarkan judul. Pencarian diterapkan saat Anda mengetik atau ketika Anda menekan Enter.

Untuk filter yang lebih rumit, gunakan opsi filter lanjutan:

- **Divisi** — Filter berdasarkan divisi organisasi
- **Penting** — Filter berdasarkan level urgensi (Penting, Normal)

Klik **Reset** untuk menghapus semua filter dan kembali ke tampilan default.

## Melihat detail regulasi

Klik pada judul regulasi di tabel untuk membuka tampilan detail. Halaman detail menampilkan:

- **Konten regulasi** — Teks lengkap dokumen regulasi
- **Detail rekam** — Divisi, kategori, urgensi, periode efektif, terlihat ke peran, terakhir diperbarui, dan dibuat oleh
- **Lampiran** — File apa pun yang dilampirkan ke regulasi (dengan tombol Lihat dan Unduh)
- **Aktivitas** — Timestamp pembuatan dan pembaruan

## Lampiran

Regulasi dapat menyertakan lampiran file. Di tampilan detail, bagian Lampiran menampilkan semua file yang dilampirkan dengan:

- **Nama file** — Nama asli file yang diunggah
- **Tipe dan ukuran file** — Informasi format dan ukuran file
- **Lihat** — Membuka pratinjau file di tab baru
- **Unduh** — Mengunduh file ke perangkat Anda

## Membuat regulasi baru

Jika Anda memiliki izin, tombol **Regulasi Baru** muncul di pojok kanan atas tabel.

1. Klik **Regulasi Baru** untuk membuka dialog pembuatan
2. Isi bidang yang diperlukan:
   - **Judul** — Nama dokumen regulasi
   - **Konten** — Teks regulasi lengkap
   - **Kategori** — Pilih kategori (Kepatuhan, HRD, atau Legal)
   - **Divisi** — Pilih divisi organisasi
   - **Penting** — Aktifkan jika ini adalah regulasi penting
   - **Tanggal Mulai** — Kapan regulasi menjadi efektif (opsional)
   - **Tanggal Berakhir** — Kapan regulasi kedaluwarsa (opsional)
   - **Terlihat Ke** — Pilih peran tertentu yang harus melihat regulasi ini (opsional)
   - **Lampiran** — Unggah file untuk dilampirkan ke regulasi (opsional)
3. Klik **Simpan** untuk membuat regulasi

## Mengedit regulasi

1. Klik tombol **Edit** pada baris regulasi apa pun di tabel (atau di halaman detail)
2. Dialog edit terbuka dengan data regulasi saat ini terisi sebelumnya
3. Buat perubahan Anda
4. Klik **Simpan** untuk menerapkan pembaruan

## Menghapus regulasi

1. Klik tombol **Hapus** pada baris regulasi (atau di halaman detail)
2. Dialog konfirmasi muncul bertanya "Apakah Anda yakin ingin menghapus regulasi ini?"
3. Klik **Hapus** untuk mengonfirmasi, atau **Batal** untuk membatalkan

<Callout type="warning">
  Menghapus regulasi tidak dapat dibatalkan.
</Callout>

## Periode efektif

Regulasi dapat memiliki periode efektif yang didefinisikan:

- **Tanggal Mulai** — Tanggal regulasi menjadi aktif
- **Tanggal Berakhir** — Tanggal regulasi kedaluwarsa
- Jika keduanya diatur, periode efektif ditampilkan sebagai rentang tanggal
- Jika hanya tanggal mulai yang diatur, ditampilkan "Dari [tanggal]"
- Jika hanya tanggal berakhir yang diatur, ditampilkan "Sampai [tanggal]"

## Divisi regulasi

Divisi adalah unit organisasi yang regulasi ditugaskan ke. Setiap regulasi menjadi milik satu divisi. Divisi dapat dikelola melalui Panel Admin jika Anda memiliki izin yang sesuai.

## Persyaratan izin

- **Melihat regulasi** memerlukan izin baca modul Regulasi
- **Membuat, mengedit, dan menghapus** regulasi memerlukan izin buat, update, dan delete modul Regulasi masing-masing
- Jika Anda tidak memiliki izin yang diperlukan, tombol **Regulasi Baru** dan tombol tindakan tidak akan terlihat
