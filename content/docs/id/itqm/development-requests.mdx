# Permintaan Pengembangan

Permintaan Pengembangan mengelola siklus lengkap pekerjaan pengembangan TI — dari submit awal melalui persetujuan, penugasan, dan pelacakan. Alur kerja dibagi menjadi tiga tampilan utama berdasarkan peran Anda: **Kembangkan Permintaan** (pengirim), **Terima Pengembangan** (persetujuan TI), dan **Setujui Pengembangan** (persetujuan divisi).

## Gambaran alur kerja permintaan

Permintaan pengembangan bergerak melalui tahap-tahap ini:

1. **Draf** — Dibuat tetapi belum dikirim
2. **Menunggu Persetujuan** — Dikirim dan menunggu persetujuan divisi
3. **Revisi** — Dikembalikan untuk perubahan
4. **Menunggu Penerimaan IT** — Disetujui dan menunggu penerimaan TI
5. **Menunggu Penugasan** — Diterima, menunggu pengembang untuk ditugaskan
6. **Sedang Dikerjakan** — Pekerjaan sedang aktif dilakukan
7. **Menunggu Verifikasi** — Selesai, menunggu verifikasi peminta
8. **Selesai** — Terverifikasi dan ditutup

## Kembangkan Permintaan

Tampilan **Kembangkan Permintaan** adalah tempat pengirim membuat, mengelola, dan melacak permintaan pengembangan mereka.

### Tabel permintaan

Tabel menampilkan semua permintaan yang telah Anda submit atau terlibat. Setiap baris menampilkan:

| Kolom | Deskripsi |
|---|---|
| Subjek | Judul permintaan |
| Jenis | Kategori permintaan (misalnya, Fitur, Perbaikan Bug) |
| Sistem | Sistem atau aplikasi target |
| Status | Status alur kerja saat ini |
| Dikirim | Tanggal dan waktu permintaan dikirim |
| Tindakan | Tindakan yang tersedia untuk permintaan |

Gunakan header kolom untuk mengurutkan dan bilah pencarian untuk memfilter permintaan.

### Membuat permintaan baru

Untuk submit permintaan pengembangan baru:

1. Klik tombol **Permintaan Baru** di pojok kanan atas halaman Kembangkan Permintaan
2. Isi bidang yang diperlukan di dialog:
   - **Subjek** — Judul jelas untuk permintaan Anda
   - **Persyaratan** — Deskripsi detail tentang apa yang Anda butuhkan
   - **Jenis** — Pilih kategori permintaan dari dropdown
   - **Sistem** — Pilih sistem target dari dropdown
   - **Lampiran** — Opsional lampirkan file pendukung
3. Klik **Submit** untuk mengirim permintaan untuk persetujuan

### Mengedit dan mengirim ulang

Ketika permintaan dikembalikan untuk **Revisi**, Anda dapat mengedit dan mengirim ulang:

1. Buka permintaan dari tabel
2. Klik **Edit** untuk memodifikasi subjek, persyaratan, jenis, sistem, atau lampiran
3. Tinjau perubahan Anda dan klik **Kirim Ulang** untuk mengirimkannya kembali ke alur kerja

## Terima Pengembangan

Tampilan **Terima Pengembangan** digunakan oleh persetujuan TI untuk meninjau permintaan masuk dan menugaskan pekerjaan pengembangan.

### Tabel penerimaan

Tabel menampilkan permintaan yang siap untuk penerimaan TI. Setiap baris menampilkan:

| Kolom | Deskripsi |
|---|---|
| Subjek | Judul permintaan |
| Jenis | Kategori permintaan |
| Sistem | Sistem target |
| Peminta | Siapa yang.submit permintaan |
| Persetujuan Divisi | Persetujuan divisi yang menyetujuinya |
| Disetujui | Tanggal persetujuan divisi |
| Status | Status alur kerja saat ini |
| Tindakan | Tindakan yang tersedia untuk permintaan |

### Menerima permintaan

Untuk menerima permintaan:

1. Klik **Terima** pada baris permintaan
2. Panel Penugasan terbuka di mana Anda dapat memilih pengembang dan tanggal jatuh tempo
3. Pilih **PIC** (Person in Charge) dari dropdown
4. Atur **Tanggal Jatuh Tempo** untuk pekerjaan
5. Klik **Tugaskan** untuk mengonfirmasi

Untuk menolak permintaan:

2. Dialog Penolakan terbuka

### Menyetujui permintaan

Untuk menyetujui permintaan:

1. Klik **Setujui** pada baris permintaan
2. Permintaan bergerak ke status **Menunggu Penerimaan IT**
3. Persetujuan TI akan menerima notifikasi untuk meninjau dan menugaskan pekerjaan

### Menolak permintaan

Untuk menolak permintaan:

1. Klik **Tolak** pada baris permintaan
2. Dialog Penolakan terbuka
3. Masukkan alasan untuk penolakan
4. Klik **Submit** untuk mengirim permintaan kembali ke peminta dalam status **Revisi**

## Tampilan detail permintaan

Mengklik permintaan apa pun di tabel membuka tampilan detail lengkapnya, yang menampilkan:

- Subjek, persyaratan, dan informasi jenis
- Detail sistem dan lampiran
- Status saat ini dan riwayat alur kerja
- PIC yang ditugaskan dan tanggal jatuh tempo (jika ditugaskan)
- Tombol tindakan yang relevan dengan status saat ini
