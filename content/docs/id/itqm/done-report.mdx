# Laporan Selesai

Laporan Selesai menyediakan pandangan terpusat dari permintaan pengembangan yang selesai. Ini memungkinkan Anda memverifikasi bahwa pekerjaan telah delievered sesuai harapan dan mengelola status registrasi.

## Tabel Laporan Selesai

Tabel menampilkan semua permintaan pengembangan yang telah ditandai sebagai selesai. Setiap baris menampilkan:

| Kolom | Deskripsi |
|---|---|
| Subjek | Judul permintaan |
| Jenis | Kategori permintaan |
| Sistem | Sistem target |
| Peminta | Siapa yang.submit permintaan |
| PIC | Pengembang yang ditugaskan |
| Tenggat | Tanggal jatuh tempo untuk pekerjaan |
| Status | Status saat ini |
| Overdue | Apakah permintaan diselesaikan setelah tanggal jatuh tempo |
| Terdaftar | Apakah permintaan telah didaftarkan |
| Tindakan | Tindakan yang tersedia untuk permintaan |

Gunakan header kolom untuk mengurutkan dan bilah pencarian untuk memfilter entri.

## Tindakan

Tergantung pada peran dan status permintaan Anda, Anda mungkin melihat tindakan berikut:

### Tandai Selesai

Ketika permintaan berada dalam status **Sedang Dikerjakan** atau **Menunggu Verifikasi**, Anda dapat menandainya sebagai selesai:

1. Klik **Tandai Selesai** pada baris permintaan
2. Permintaan bergerak ke status **Selesai**
3. Peminta akan menerima notifikasi untuk memverifikasi penyelesaian

### Verifikasi

Ketika permintaan berada dalam status **Menunggu Verifikasi**, peminta dapat memverifikasi penyelesaian:

1. Klik **Verifikasi** pada baris permintaan
2. Permintaan dikonfirmasi sebagai selesai dan ditutup
3. Permintaan bergerak ke status **Selesai** secara permanen

### Lewati Selesai

Untuk permintaan yang perlu dipindahkan secara manual ke status Selesai di luar alur kerja normal:

1. Klik **Lewati Selesai** pada baris permintaan
2. Permintaan ditutup paksa tanpa memerlukan verifikasi

### Alihkan Registrasi

Tindakan **Alihkan Registrasi** memungkinkan Anda menandai atau menghapus tanda permintaan sebagai terdaftar:

1. Klik **Alihkan Registrasi** pada baris permintaan
2. Status registrasi diperbarui sesuai

Registrasi digunakan untuk melacak apakah permintaan yang selesai telah didaftarkan secara formal di sistem.

## Indikator overdue

Kolom **Overdue** menunjukkan apakah permintaan diselesaikan setelah tanggal jatuh tempo. Ini membantu mengidentifikasi keterlambatan pengiriman dan melacak tingkat penyelesaian tepat waktu.

- Permintaan overdue disorot secara visual
- Dashboard juga menampilkan informasi overdue di widget Tenggat Waktu yang Akan Datang

## Detail permintaan

Klik pada permintaan apa pun di Laporan Selesai untuk membuka tampilan detail lengkapnya, yang menampilkan riwayat lengkap termasuk siapa yang mengerjakannya, kapan diselesaikan, dan catatan verifikasi apa pun.
