# Pengaturan Ulang Kata Sandi Pertama Kali

Ketika Anda masuk untuk pertama kalinya menggunakan kata sandi default, CSSI meminta Anda membuat kata sandi baru sebelum melanjutkan. Ini adalah alur wajib.

## Atur kata sandi Anda

<Steps>
  <Step>

### Langkah 1 - Masuk dengan kata sandi default

Masuk menggunakan ID Karyawan dan kata sandi default yang disediakan untuk akun Anda.

Lihat [Masuk](./sign-in) untuk detail.

  </Step>
  <Step>

### Langkah 2 - Buat kata sandi baru

CSSI menampilkan halaman pengaturan ulang kata sandi. Masukkan kata sandi baru Anda.

  </Step>
  <Step>

### Langkah 3 - Konfirmasi kata sandi baru

Masukkan kembali kata sandi baru Anda untuk mengonfirmasinya.

  </Step>
  <Step>

### Langkah 4 - Selesaikan pengaturan ulang kata sandi

Setelah kata sandi baru berhasil disimpan, Anda harus masuk kembali. Anda tidak akan dilanjutkan secara otomatis.

<Callout type="warning">
  Mengatur ulang kata sandi tidak akan melanjutkan masuk Anda yang sedang berjalan.
  Masuk kembali menggunakan kata sandi baru Anda.
</Callout>

  </Step>
  <Step>

### Langkah 5 - Masuk kembali

Kembali ke halaman masuk dan autentikasi menggunakan ID Karyawan yang sama dan kata sandi baru Anda.

Setelah masuk berhasil, Anda diarahkan ke Portal.

  </Step>
</Steps>

## Ringkasan alur pertama kali

```
Kata sandi default
→ Atur ulang kata sandi
→ Masuk kembali
→ Portal
```

Lihat [dokumentasi Portal](/docs/id/portal) setelah Anda menyelesaikan masuk.
