# Lupa Kata Sandi

Jika Anda tidak dapat mengingat kata sandi Anda, gunakan alur Lupa Kata Sandi untuk memverifikasi identitas Anda melalui email terdaftar dan membuat kata sandi baru.

## Ringkasan alur lupa kata sandi

```
Lupa Kata Sandi
→ OTP Email
→ Atur kata sandi baru
→ Masuk kembali
→ Portal
```

Lihat [dokumentasi Portal](/docs/id/portal) setelah Anda menyelesaikan masuk.
