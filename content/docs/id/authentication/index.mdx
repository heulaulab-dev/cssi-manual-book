## Cara kerja autentikasi

**Pengguna yang sudah pernah masuk:**

```
Masuk → Portal
```

**Pengguna baru:**

```
Masuk dengan kata sandi default
→ Atur ulang kata sandi
→ Masuk kembali
→ Portal
```

**Lupa kata sandi:**

```
Lupa Kata Sandi
→ OTP Email
→ Atur kata sandi baru
→ Masuk kembali
→ Portal
```
