# Dashboard

The Intranet Dashboard gives you a consolidated view of internal company information. The widgets shown can vary depending on your role and permissions.

## Dashboard greeting

When you first load the Dashboard, you'll see a personalized greeting based on the current time of day. The greeting appears at the top of the page. A **Refresh** button is available in the top-right corner to reload the widget data.

## Intranet Announcements

The Intranet Announcements widget appears at the top of the Dashboard and highlights internal and managerial information so you can see important updates at a glance.

- This is a summary view — only the most recent announcements are shown
- Each announcement displays its title, a brief excerpt, date, and badges for **New** or **Urgent** items
- Click on an announcement to read the full content
- Use the **View all intranet announcements** link at the bottom to open the complete list

## Notifications

The Notifications widget provides a quick view of your latest alerts and messages.

- Each notification displays its title, message, and date
- Use the **View all notifications** link to open the full notifications page

## Regulations

The Regulations widget provides a summary of regulatory documents across three categories: Compliance, HRD, and Legal.

- A category summary strip at the top shows the count for each category
- Recent regulations from each category are listed below with title and brief excerpt
- Use the category links to navigate to the full regulation list for each category

## Development

The Development widget gives you a quick view of IT development requests and their current status.

- You can filter by status using the category tabs at the top of the widget
- Each entry shows the request subject, a brief description, status badge, and the requester's name
- Click on a request to view more details in ITQM

Visible status categories:

| Status | Description |
|---|---|
| In Progress | Work is actively being performed |
| Pending Approval | Awaiting approval from the requestor or business unit |
| Pending Assignment | Waiting for an IT developer to be assigned |
| Pending IT Accept | Awaiting IT acceptance after completion |
| Pending Verification | Waiting for verification by the requestor |
| Revision | Changes are being made based on feedback |
| Draft | Still being prepared, not yet submitted |
| Done | Completed and closed |

## Daily Checklists

The Daily Checklists widget gives users a quick view of operational checklist activity relevant to their division.

- Each entry shows the task name, part/team name, number of checked items, status badge, and who submitted it
- Use the category tabs to filter by status: **All**, **Pending**, **Approved**, or **Rejected**
- Click on a checklist entry to view details and take action in Daily Operation

## Module navigation bar

If you have access to multiple dashboard modules (Announcements, Regulations, Notifications), a module navigation bar appears below the widgets. Use it to switch between module-specific KPI cards, charts, and quick actions.

- Click a module tab to view its KPIs and charts
- Each module shows key metrics as cards (e.g., Total Announcements, Urgent Announcements)
- Charts visualize data distribution (e.g., Urgent Distribution pie chart, Regulations by Category bar chart)
- Quick action buttons let you jump directly to management pages
