# Admin Panel

The Admin Panel provides administrative tools for managing users, roles, permissions, audit logs, system announcements, and regulation divisions. Access to the Admin Panel is restricted to users with administrative roles.

## Accessing the Admin Panel

The Admin Panel is accessible from the sidebar when you have administrative permissions. Navigate to **Administration** in the sidebar to access the admin workspace.

If you don't have administrative access, the Administration section will not appear in your sidebar.

## Admin Dashboard

The Admin Dashboard provides an operational overview of your system:

### User overview

Shows summary metrics for user accounts:

- **Total** — All user accounts in the system
- **Active** — Currently active user accounts (with a green indicator)
- **Inactive** — Inactive user accounts

### Activity overview

Shows the number of audit events recorded in the last 24 hours, giving you a quick view of recent administrative activity.

### Quick actions

Common administrative tasks available as buttons:

- **Create User** — Open the Users page to add a new user
- **Roles & Permissions** — Open the Roles page to manage role assignments
- **New Announcement** — Open the System Announcements page to create a new announcement
- **View Audit Logs** — Open the Audit Logs page to review activity

### Recent activity

A feed of the most recent administrative actions, showing:

- The action performed
- The entity type (User, Role, Permission, Login, Announcement)
- Who performed the action
- When it occurred (with relative time display)

Click **View all** to open the full Audit Logs page.

### Viewing users

The user table displays all user accounts with relevant information. Use the search bar and filters to find specific users.

### Creating a new user

1. Navigate to **Administration** > **Users**
2. Click the button to create a new user
3. Fill in the required user information
4. Save the new user account

### Managing user accounts

From the Users page, you can:

- View user details
- Edit user information
- Activate or deactivate user accounts
- Assign roles to users

### Viewing roles

The roles table displays all defined roles with their names and descriptions.

### Managing roles

From the Roles page, you can:

- View role details and assigned permissions
- Edit role names and descriptions
- Assign or remove permissions from roles
- Create new roles

### Understanding permissions

Each role has a set of module permissions that determine what actions users with that role can perform. Permissions are organized by module and include actions like Create, Read, Update, Delete, Approve, Reject, Export, Import, and Print.

### Viewing audit logs

The audit log table displays all recorded actions with:

- **Action** — The type of action performed
- **Entity** — The type of entity affected (User, Role, Permission, etc.)
- **User** — Who performed the action
- **Timestamp** — When the action occurred

### Filtering audit logs

Use the search bar and filters to find specific audit entries. You can filter by action type, entity type, user, and date range.

### Managing system announcements

From this page, you can:

- View all system announcements
- Create new system announcements
- Edit existing announcements
- Delete announcements

System announcements differ from intranet announcements in that they are managed at the system level and may be displayed across multiple applications.

## Permission requirements

Access to the Admin Panel and its sections requires appropriate administrative permissions:

- **Admin Dashboard** — Requires an administrative role
- **Users** — Requires user management permissions
- **Roles** — Requires role management permissions
- **Audit Logs** — Requires audit log read permissions
- **System Announcements** — Requires system announcement management permissions
- **Divisions** — Requires system administrator access

If you don't have the required permissions, the corresponding sections will not be accessible.
