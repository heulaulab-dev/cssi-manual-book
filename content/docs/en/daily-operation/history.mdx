# History

The History page lets you browse approved checklist records for any business date. You can view the full details of each approved submission, including all checklist entries, comments, and actions taken.

## Business Date picker

Use the **Business Date** picker in the toolbar to select the date you want to review. The approved records list updates to match the selected date.

## Summary strip

The summary strip displays four metrics for the selected date:

| Metric | Description |
|---|---|
| **Approved Records** | Total number of approved submissions for the date |
| **Checklist Items** | Total number of checklist items across all records |
| **Completed Items** | Number of items marked complete out of total |
| **Approvers** | Number of distinct approvers who reviewed submissions |

## Report list table

The report list table displays all approved submissions for the selected date:

| Column | Description |
|---|---|
| **Date** | The business date of the submission |
| **Task / Part** | The task and part name |
| **Submitted By** | Who submitted the checklist |
| **Approved By** | Who approved the submission |
| **Checklist** | Number of completed items out of total |
| **View** | Button to inspect the full details |

Click on a row or the **View** button to see the full submission details in the right panel.

### Pagination

Use the **Previous** and **Next** buttons at the bottom of the report list to navigate between pages of results. The current page number and total pages are displayed.

## Report detail panel

When you select a report from the list, the detail panel on the right shows:

- **Part name** and **Task name**
- **Status** badge (always Approved)
- **Business Date**
- **Checklist Summary** — completed items count
- **Submitted By** and **Submitted At**
- **Approved By** and **Approved At**
- **Checklist entries table** — all items with completion status, comments, and actions taken

## Empty states

If no approved records exist for the selected date, you will see a message suggesting you try another business date.

<Callout type="info">
  History only shows approved submissions. Rejected or draft submissions are
  not included in the history view.
</Callout>
