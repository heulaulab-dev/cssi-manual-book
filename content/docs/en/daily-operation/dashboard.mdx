# Dashboard

The Dashboard provides a consolidated view of your daily operational activity. It shows key metrics at a glance so you can quickly identify what needs attention.

## Business Date

The Dashboard displays the current business date in the toolbar at the top of the page. This date determines which checklist data and submissions are shown.

## Metric cards

The top of the Dashboard displays five metric cards that summarize today's operational status:

| Card | Description |
|---|---|
| **Today's Tasks** | Total number of tasks configured for today's checklist |
| **Parts Requiring Work** | Number of parts that are in draft, rejected, or incomplete |
| **Pending Approval** | Number of checklist submissions waiting for review |
| **Rejected / Corrections** | Number of parts that were rejected and need corrections |
| **Completed / Approved** | Number of parts that have been approved |

## Today's Operations

The Today's Operations section lists the checklist parts that need your attention, sorted by status priority (rejected first, then draft, pending, and approved).

Each row shows:

- **Task / Part name** — The task and part this checklist belongs to
- **Status badge** — Current status (Draft, Pending, Approved, or Rejected)
- **Progress** — Number of completed items out of total, with a progress bar
- **Context** — Additional details such as correction reasons or submission times

Click **Open Today** to navigate to the full Today's Checklist page.

## Approvals

If you have approval permissions, the Approvals section on the Dashboard shows three summary cards:

- **Waiting for review** — Pending submissions awaiting your action
- **Approved today** — Submissions approved so far today
- **Rejected today** — Submissions rejected so far today

Click **View Approvals** to open the full Approvals page.

## Status Context

The Status Context section at the bottom of the Dashboard shows the overall completion progress across today's configured checklist. It displays the number of items completed out of the total, along with a percentage and progress bar.

## Intranet Announcements

The Intranet Announcements widget appears at the top of the Dashboard and highlights internal updates so you can see important information without leaving Daily Operation.

- Each announcement displays its title, a brief excerpt, and date
- Click on an announcement to read the full content

<Callout type="info">
  The Dashboard data is based on the current business date. Use the Business
  Date picker on the Today's Checklist page to view data for a different date.
</Callout>
