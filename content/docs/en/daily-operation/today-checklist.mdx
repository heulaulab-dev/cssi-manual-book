# Today's Checklist

The Today's Checklist page is your primary workspace for completing daily operational tasks. Here you mark checklist items as done, add comments, and submit completed parts for approval.

## Summary strip

The summary strip displays seven metrics for the selected date:

| Metric | Description |
|---|---|
| **Tasks** | Total number of tasks configured for the date |
| **Parts** | Total number of parts across all tasks |
| **Completed** | Number and percentage of completed checklist items |
| **Draft** | Number of parts still in draft status |
| **Pending** | Number of parts submitted and awaiting approval |
| **Rejected** | Number of parts that were rejected |
| **Approved** | Number of parts that have been approved |

## Task sections

Tasks are displayed as collapsible sections. Each task shows:

- **Task name** and sequence number
- **Parts count** badge indicating how many parts belong to the task
- **Completion progress** — percentage and item counts

Click the expand/collapse chevron on the left of a task to show or hide its parts.

## Part sections

Within each task, parts are displayed as nested collapsible sections. Each part shows:

- **Part name** and part number (e.g., 1.1)
- **Status badge** — Draft, Pending, Approved, or Rejected
- **Completion count** — Number of completed items out of total
- **Saved time** — When the part was last saved or submitted

### Part status

Parts can have one of four statuses:

| Status | Meaning |
|---|---|
| **Draft** | Not yet submitted; you can still edit and save |
| **Pending** | Submitted and waiting for approval |
| **Approved** | Approved by a supervisor; read-only |
| **Rejected** | Rejected by a supervisor; corrections required |

## Checklist table

When you expand a part, the checklist table is displayed with the following columns:

| Column | Description |
|---|---|
| **#** | Sequential item number |
| **Checklist Item** | The name of the checklist item |
| **Complete** | Checkbox to mark the item as complete or incomplete |
| **Comment** | Optional text field for adding comments |
| **Action Taken** | Optional text field for recording actions performed |

### Completing checklist items

1. Expand a task section by clicking its name or chevron
2. Expand the part you want to work on
3. For each checklist item, click the **Complete** checkbox to mark it as done
4. Optionally add a **Comment** or **Action Taken** for any item

## Saving and submitting

Once you have completed the checklist items for a part, you can save your progress or submit for approval.

### Save Part

Click **Save Part** to save your progress without submitting. Use this when you are not yet ready to submit (e.g., you still have items to complete). The part remains in Draft status.

### Submit Part / Resubmit Part

Click **Submit Part** to send the completed part to your supervisor for approval. This button is only available when:

- All checklist items in the part are marked complete
- The part has been saved at least once

If a part was previously rejected, the button changes to **Resubmit Part**. You can review the rejection reason in the red alert banner above the checklist table.

### Read-only parts

Parts in Pending or Approved status are read-only. The checklist table displays your submitted values as static text, and the checkboxes and text fields are disabled. A **Read-only** badge appears next to the part.

## Empty states

If no checklist tasks are configured for the selected date, you will see a message indicating that no tasks are available. This is normal for dates without scheduled operations.
