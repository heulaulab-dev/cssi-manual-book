The CSSI ecosystem consists of multiple applications that share a common navigation experience. This guide explains how to move between applications and navigate within them.

## Switching between applications

The **app switcher** appears in the top-left area of every CSSI application. It lists all applications you have access to:

- **Portal** — Central hub and dashboard
- **CRM** — Sales and trading operations
- **Intranet** — Internal communications and company information
- **Flowra** — Financial workflow automation
- **ITQM** — IT quality management and development workflows
- **Daily Operation** — Daily operational checklists

Click any application name to switch directly to it. You do not need to return to Portal first.

## Sidebar navigation

Each application has its own sidebar with navigation items organized into groups. The sidebar provides access to the main features of that application.

### Sidebar features

- **Search** — Type in the search box to find navigation items quickly. The keyboard shortcut **F** focuses the search field, and **Escape** clears it.
- **Expand/Collapse** — Click the sidebar toggle to minimize or expand the sidebar.
- **Theme toggle** — Switch between Light and Dark themes from the sidebar footer.

### Focused workspaces

Some pages use a focused sidebar that shows only the relevant navigation for that section. For example, when you open **Account** or **Administration**, the sidebar switches to show only items for that section. A **Back** button appears to return you to the main application navigation.

## Command menu

Press **Cmd+K** (Mac) or **Ctrl+K** (Windows/Linux) to open the command menu. The command menu lets you:

- Search for and navigate to any page across the current application
- Access common actions quickly
- Switch between applications

## Breadcrumbs

Each page shows a breadcrumb trail below the top navigation bar, indicating your current location within the application. Click any breadcrumb segment to navigate back to that level.

## Module tabs

Some applications display module tabs below the top navigation bar. These tabs let you switch between different functional areas within the same application.
