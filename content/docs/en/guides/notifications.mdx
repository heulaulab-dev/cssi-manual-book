# Notifications

Every CSSI application provides a Notifications page where you can view, filter, and manage alerts. Access it by clicking the **notification bell** icon in the top-right corner of any page, or by navigating to the Notifications page from the sidebar.

## Notification categories

Notifications are organized into categories, accessible via filter buttons at the top of the page:

| Filter | Description |
|---|---|
| **All** | Shows every notification across all categories |
| **Unread** | Shows only notifications you have not yet read |
| **Announcements** | System and intranet announcements |
| **Mentions** | Notifications where you were mentioned |
| **Updates** | Status changes and activity updates |
| **Actions** | Items requiring your attention or response |

Each filter button displays an unread count badge so you can see at a glance how many unread notifications exist in each category.

## Reading notifications

Each notification displays:

- **Title** — A brief description of the event
- **Time** — When the notification was generated
- **Category badge** — Which category the notification belongs to
- **Read/unread indicator** — Unread notifications are highlighted

Click on a notification to view its full details and take any available actions.

## Managing notifications

Click the **three-dot menu** on any notification to access additional actions:

| Action | Description |
|---|---|
| **Mark as read** | Mark a single notification as read (available for unread notifications only) |
| **Snooze for 1 hour** | Temporarily hide the notification; it will reappear after one hour |
| **Delete** | Permanently remove the notification |

## No notifications

If there are no notifications in a category, you will see a message indicating that no notifications are available for that filter. This is normal and means everything is up to date.
