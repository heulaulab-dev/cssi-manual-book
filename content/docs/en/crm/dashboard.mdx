# Dashboard

The CRM Dashboard gives you an overview of sales activity, stock market data, and trading performance. It is the first page you see when you open CRM.

## Dashboard header

The top of the Dashboard displays a greeting and the page title. A **Refresh** button in the top-right corner reloads all widget data. A timestamp shows when the data was last updated.

## Sales Workflow

The Sales Workflow widget is the primary overview of your sales pipeline. It displays four key metrics and a bar chart.

### Metric tiles

Four clickable tiles show the current count for each sales stage:

| Tile | Description |
|---|---|
| **Leads** | Number of active leads in the system |
| **Prospects** | Number of qualified prospects |
| **Opportunities** | Number of deals in the pipeline |
| **Accounts** | Number of managed accounts |

Click any tile to navigate directly to that section. The **New opportunity** button in the widget header opens the opportunity creation form.

### Records by Module chart

A bar chart on the right side of the widget shows the distribution of records across sales modules. This helps you see where activity is concentrated.

### Footer link

Click **Open sales workspace** at the bottom of the widget to navigate to the Leads page.

## Stock

The Stock widget provides a market summary directly on the CRM Dashboard.

- Use the **search box** at the top of the widget to find and select a stock by name or code
- The widget displays the current price, price change, and a chart showing price history
- Use the **time range selector** to view different periods (1D, 5D, 1M, 3M, 1Y)
- Click **Open stocks** to view the full stock management interface

Visible elements:

- Stock identifier and name (selected via search)
- Current price in Indonesian Rupiah
- Price change (absolute and percentage) with color-coded indicator (green for positive, red for negative)
- Previous close price
- Price chart with interactive tooltip showing date and price

## Rankings

The Rankings widget provides a summarized ranking view of portfolio and trading performance.

- Toggle between **P/L Rank** and **Trading Rank** using the selector in the widget header
- The top 5 entries are displayed for each ranking type

### P/L Rank columns

| Column | Description |
|---|---|
| Rank | Position in the ranking |
| Stock | Stock code and name |
| Avg price | Average transaction price |
| Close price | Latest closing price |
| Daily P/L amount | Profit or loss for the day |
| Stock value | Total market value |
| Total balance | Account balance |
| P/L rate | Percentage return (color-coded) |

### Trading Rank columns

| Column | Description |
|---|---|
| Rank | Position in the ranking |
| Stock | Stock code and name |
| Open price | Opening price for the period |
| Close price | Closing price for the period |
| Change price | Absolute price change |
| Total lot | Number of shares traded |
| Total value | Total traded value |
| Total volume | Trading volume |
| Change rate % | Percentage change (color-coded) |

Click **View all P/L rankings** or **View all trading rankings** to open the full rankings page in the Trend Catch section.

## Additional widgets

Depending on your role and permissions, you may also see:

- **Developments** — A summary of IT development request activity
- **Daily Checklists** — A view of operational checklist activity relevant to your division

<Callout type="info">
  The widgets shown on your Dashboard may vary depending on your role,
  division, and available data. If you do not see a widget you expect, contact
  your administrator.
</Callout>
