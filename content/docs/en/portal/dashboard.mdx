# Dashboard

The Portal Dashboard gives you a consolidated view of information from across CSSI applications. The widgets shown can vary depending on your division and permissions.

## Dashboard greeting

When you first load the Dashboard, you'll see a personalized greeting such as "Good morning, John" based on the current time of day. The greeting appears at the top of the page. A **Refresh** button is available in the top-right corner to reload the widget data.

## Intranet Announcements

The Intranet Announcements widget appears at the top of the Dashboard and highlights internal and managerial information so you can see important updates without leaving Portal.

- This is a summary view — only the most recent announcements are shown
- Each announcement displays its title, a brief excerpt, date, and badges for **New** or **Urgent** items
- Click on an announcement to read the full content within Portal
- Use the **View all intranet announcements** link at the bottom to open the complete list in Intranet

## Development

The Development widget gives you a quick view of IT development requests and their current status.

- You can filter by status using the category tabs at the top of the widget
- Each entry shows the request subject, a brief description, status badge, and the requester's name
- Click on a request to view more details in ITQM

Visible status categories:

| Status | Description |
|---|---|
| In Progress | Work is actively being performed |
| Pending Approval | Awaiting approval from the requestor or business unit |
| Pending Assignment | Waiting for an IT developer to be assigned |
| Pending IT Accept | Awaiting IT acceptance after completion |
| Pending Verification | Waiting for verification by the requestor |
| Revision | Changes are being made based on feedback |
| Draft | Still being prepared, not yet submitted |
| Done | Completed and closed |

## Daily Checklists

The Daily Checklists widget gives users a quick view of operational checklist activity relevant to their division.

- Each entry shows the task name, part/team name, number of checked items, status badge, and who submitted it
- Use the category tabs to filter by status: **All**, **Pending**, **Approved**, or **Rejected**
- Click on a checklist entry to view details and take action in Daily Operation

## Stock

The Stock widget provides a market summary directly on the Portal Dashboard.

- Use the search box at the top of the widget to find and select a stock by name or code
- The widget displays the current price, price change, and a chart showing price history
- Use the time range selector to view different periods (e.g., 1D, 5D, 1M, 3M, 1Y)
- Click **Open stocks** to view the full stock management interface in CRM

Visible elements:

- Stock identifier and name (selected via search)
- Current price in Indonesian Rupiah
- Price change (absolute and percentage) with color-coded indicator (green for positive, red for negative)
- Price chart with interactive tooltip showing date and price
- Time range selector

## Rankings

The Rankings widget provides a summarized ranking view of portfolio and trading performance.

- Toggle between **P/L Rank** and **Trading Rank** using the selector in the widget header
- **P/L Rank** shows the top 5 stocks ranked by profit and loss performance
- **Trading Rank** shows the top 5 stocks ranked by trading activity

### P/L Rank columns

| Column | Description |
|---|---|
| Rank | Position in the ranking |
| Stock | Stock code and name |
| Avg price | Average transaction price |
| Close price | Latest closing price |
| Daily P/L amount | Profit or loss for the day |
| Stock value | Total market value |
| Total balance | Account balance |
| P/L rate | Percentage return (color-coded) |

### Trading Rank columns

| Column | Description |
|---|---|
| Rank | Position in the ranking |
| Stock | Stock code and name |
| Open price | Opening price for the period |
| Close price | Closing price for the period |
| Change price | Absolute price change |
| Total lot | Number of shares traded |
| Total value | Total traded value |
| Total volume | Trading volume |
| Change rate % | Percentage change (color-coded) |

Click **View all P/L rankings** or **View all trading rankings** to open the full rankings page in CRM.
