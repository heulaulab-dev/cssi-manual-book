# Navigating Applications

Portal is the starting point for CSSI, while detailed workflows happen in the related application.

## Using the application navigation

The top application navigation in Portal lets you switch between applications.

Current applications shown:

- Portal
- CRM
- Intranet
- Flowra
- ITQM
- Daily Operation

## Using dashboard shortcuts

Some dashboard widgets provide "View all" or similar actions that take you toward the related workflow.

Examples visible in the current UI:

- View all intranet announcements
- View all developments
- View all checklists
- View all stocks
- View all rankings

## Using the Applications section

The Applications section at the bottom of the Portal dashboard provides cards for each available CSSI application. Click a card to open that application.
