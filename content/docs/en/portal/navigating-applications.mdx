# Navigating Applications

Portal is the starting point for CSSI, while detailed workflows happen in the related application. This guide explains how to move between Portal and other applications.

## Using the top application navigation

The top navigation bar in Portal lets you switch between applications. When you are in Portal, you can click on the name of another application to open it in a new tab.

Current applications shown:

- Portal
- CRM
- Intranet
- FLOWRA
- ITQM
- Daily Operation

## Using the Applications section

The Applications section at the bottom of the Dashboard provides cards for each available CSSI application. Each card shows:

- The application name
- A brief description
- An **Open \{App Name\}** button

Click the **Open** button to launch the application.

## Using dashboard widget actions

Some dashboard widgets provide action buttons that take you toward the related workflow in another application:

| Widget | Action | Where it leads |
|---|---|---|
| Intranet Announcements | **View all intranet announcements** | Intranet application |
| Development | **Add development request** / **View all developments** | ITQM application |
| Daily Checklists | **Add daily checklist** / **View all checklists** | Daily Operation application |
| Stock | **Open stocks** / **View all stocks** | CRM application |
| Rankings | **Open P/L rankings** / **Open trading rankings** | CRM application |

## Using the notification bell

Click the **notification bell** icon in the top-right corner of the page to view your notifications. From there, you can:

- Filter notifications by category (All, Security, Environment, Devices)
- Mark notifications as read
- Navigate to the source of each notification

## Using Account settings

Click on your **profile icon or name** in the top-right corner to access:

- **Account** — Manage your profile, security settings, and preferences
- **Sign out** — Log out of Portal
