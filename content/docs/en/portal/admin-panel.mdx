# Admin Panel

> **Access restricted.** The Admin Panel is only available to users with administrator privileges. If you do not see the Admin option in the sidebar, you do not have permission to access these features. Contact your system administrator to request access.

The Admin Panel provides tools for managing users, roles, permissions, system announcements, and reviewing administrative activity.

## Admin Overview

The overview page displays key metrics and quick actions:

### User Overview

Shows the total number of users, along with counts of active and inactive accounts.

### Activity (24h)

Shows the number of audit events in the last 24 hours.

### Quick Actions

| Button | What it does |
|---|---|
| **Create User** | Open the user management page to add new users |
| **Roles & Permissions** | Manage role definitions and their permissions |
| **New Announcement** | Create a new system announcement |
| **View Audit Logs** | Browse the full audit log history |

### Recent Activity

Shows the five most recent administrative actions across the system, including who performed the action, what was changed, and when. Click **View all** to see the complete history.

## Users

The Users page lets administrators view and manage user accounts.

- Search and filter users by name, email, or status
- View user details including their roles and access levels
- Create new user accounts
- Update existing user information
- Deactivate or reactivate accounts

## Roles & Permissions

The Roles & Permissions page lets administrators define what each role can do within the system.

- View existing roles and their assigned permissions
- Create new roles with custom permission sets
- Edit existing roles to adjust access levels
- Assign users to specific roles

## Audit Logs

The Audit Logs page provides a complete record of administrative actions taken in the system.

- Review who performed each action and when
- Filter logs by action type, entity, or date range
- Track changes to users, roles, and system settings

## System Announcements

The System Announcements page lets administrators create, edit, and manage announcements that appear to all users.

- Create new announcements with a title, content, and urgency level
- Edit or remove existing announcements
- Mark announcements as urgent to ensure they are prominently displayed
- Attach supporting documents to announcements

Announcements created here will appear in the announcement modal that users see when they log in, and in the System Announcements widget on the Dashboard.
