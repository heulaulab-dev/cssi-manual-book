# Notifications

The Notifications page lets you view, filter, and manage alerts from across the CSSI system. Access it by clicking the **notification bell** icon in the top-right corner of the Dashboard, or by navigating directly to the Notifications page.

## Notification categories

Notifications are organized into four categories, accessible via tabs at the top of the page:

| Tab | Description |
|---|---|
| **All** | Shows every notification across all categories |
| **Security** | Alerts related to account security, including login activity and password changes |
| **Environment** | System and environment-related notifications |
| **Devices** | Notifications about your devices and active sessions |

## Reading notifications

Each notification displays:

- **Title** — A brief description of the event
- **Time** — When the notification was generated
- **Category badge** — Which category the notification belongs to
- **Read/unread indicator** — Unread notifications are highlighted

Click on a notification to view its full details and take any available actions.

## Marking notifications as read

- Single-click a notification to mark it as read
- Use the filter tabs to quickly find specific types of notifications
- Use the **All** tab to see everything at once

## No notifications

If there are no notifications in a category, you will see a message indicating that no notifications are available for that filter. This is normal and means everything is up to date.
