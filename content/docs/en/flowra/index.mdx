# Flowra

Flowra supports account opening and related financial onboarding workflows within the CSSI ecosystem. It guides users through the process of creating and managing new accounts.

## What this application is for

Flowra provides the tools and workflows needed to open new accounts and complete financial onboarding tasks.

## What you can do

- Start an account opening workflow for a new customer account.
- Track onboarding progress through the workflow.
- Complete documentation and verification requirements for new accounts.
