# Dashboard

The Flowra Dashboard gives you a consolidated view of your account opening workload. It shows current queue counts, recent activity, and provides quick access to the areas you work with most.

## Dashboard header

The top of the Dashboard displays a **Dashboard** title with an **OVERVIEW** subtitle. A **Refresh** button in the top-right corner lets you reload all widget data.

## Opening Account Overview

The Opening Account Overview section displays seven metric cards, each showing a count of accounts in a particular status:

| Metric | What it counts |
|---|---|
| Total OA Process | All opening accounts currently in the system |
| Branch Verification | Accounts pending branch-level verification |
| Send to CSO | Accounts sent to compliance for review |
| CSO Verification | Accounts currently under compliance verification |
| Return to Branch | Accounts returned to Sales/Branch for follow-up |
| Cancelled | Accounts that have been cancelled |
| Converted | Accounts that have been successfully converted |

Each card displays an icon, label, and the current count. These metrics update automatically when you click **Refresh**.

## Queue previews

Below the overview metrics, the Dashboard shows two queue preview panels side by side:

### CSO Queue

Shows opening accounts currently waiting for CSO review and verification. Each entry displays the client name, date, and a **Waiting Review** badge. Click **View all CSO queue** to open the full CSO Queue.

## Latest Opening Accounts

The Latest Opening Accounts section displays the five most recently created opening accounts. Each entry shows the client name and creation date. Click on any entry to open its detail page, or click **View all opening accounts** to see the full list.

## Empty states

When a section has no data, it displays a message explaining what will appear there. For example, if no accounts are waiting for CSO review, the CSO Queue preview will show **No accounts waiting for CSO review** with a note that new accounts will appear when they are sent to CSO.

## Error states

If a section fails to load due to a connection issue or temporary error, a **Retry** button is displayed. Click **Retry** to attempt reloading that section.
