# ITQM

ITQM supports IT quality management and development request workflows within the CSSI ecosystem. It provides the tools for managing IT service requests and tracking development activity.

## What this application is for

ITQM manages IT service and development requests, from submission through approval and implementation.

## What you can do

- Submit development requests and IT service requests.
- Track request status throughout the workflow.
- Manage IT quality processes and approval activities.
