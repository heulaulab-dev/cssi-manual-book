# ITQM

ITQM is the IT Quality Management application within CSSI. It manages the full lifecycle of development requests — from submission through approval, assignment, implementation, and verification. It also provides issue tracking and team workload management.

## What ITQM is for

- **Submit development requests** — Request new features, bug fixes, or system improvements from IT
- **Track request status** — Follow every request through its workflow stages
- **Manage approvals** — Route requests through the appropriate approval channels
- **Assign work** — Assign development tasks to team members with due dates
- **Verify completion** — Review and verify delivered work before marking it done
- **Track issues** — Log and manage issues with priority, status, and assignment
- **Visualize work** — View team workload and progress on a Kanban board

## What you can do

- Create, edit, and resubmit development requests
- Accept or reject incoming requests as an IT approver
- Approve or reject requests as a division approver
- Assign developers and due dates to accepted requests
- Mark work as done and verify completion
- Create and manage issues with priorities and statuses
- View work items on a Kanban board with drag-and-drop
- Configure request types and system types
- Monitor your workload and upcoming deadlines on the Dashboard

## How ITQM fits into CSSI

ITQM handles development and IT quality workflows. For a consolidated view across all applications, see [Portal](../portal/).

```
ITQM
  → submit and manage development requests
  → assign and track development work
  → verify and close completed work
  → track and manage issues
```

## Getting around

ITQM is organized into these main areas:

- **Dashboard** — Your personalized overview with KPIs, workload, and upcoming deadlines
- **Development Requests** — Submit and manage the full request lifecycle
- **Done Report** — View completed work and verify or override completion status
- **Issues** — Track issues in a list view or on a Kanban board
- **Configuration** — Manage request types and system types (authorized users only)
