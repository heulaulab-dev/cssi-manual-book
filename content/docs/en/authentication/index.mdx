## How authentication works

**Returning user:**

```
Sign in → Portal
```

**First-time user:**

```
Sign in with default password
→ Change password
→ Sign in again
→ Portal
```

**Forgot password:**

```
Forgot Password
→ Email OTP
→ Set new password
→ Sign in again
→ Portal
```
