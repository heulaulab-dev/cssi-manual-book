# First-Time Password Change

When you sign in for the first time using your default password, CSSI requires you to create a new password before continuing. This is a mandatory flow.

## Change your password

<Steps>
  <Step>

### Step 1 - Sign in with the default password

Sign in using your Employee ID and the default password that was provided for your account.

See [Sign In](./sign-in) for details.

  </Step>
  <Step>

### Step 2 - Create a new password

CSSI displays the password-change screen. Enter your new password.

  </Step>
  <Step>

### Step 3 - Confirm the new password

Re-enter your new password to confirm it.

  </Step>
  <Step>

### Step 4 - Complete the password change

After the new password is successfully saved, you must sign in again. You are not automatically continued.

<Callout type="warning">
  Changing your password does not automatically continue your existing sign-in.
  Sign in again using your new password.
</Callout>

  </Step>
  <Step>

### Step 5 - Sign in again

Return to the sign-in page and authenticate using the same Employee ID and your new password.

After successful sign-in, you are directed to Portal.

  </Step>
</Steps>

## First-time flow summary

```
Default password
→ Change password
→ Sign in again
→ Portal
```

See [Portal documentation](/docs/portal) after you complete sign-in.
