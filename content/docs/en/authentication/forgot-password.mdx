# Forgot Password

If you cannot remember your password, use the Forgot Password flow to verify your identity through your registered email and create a new password.

## Reset your password

<Steps>
  <Step>

### Step 1 - Start Forgot Password

Select the Forgot Password option from the sign-in page.

## Forgot password flow summary

```
Forgot Password
→ Email OTP
→ Set new password
→ Sign in again
→ Portal
```

See [Portal documentation](/docs/portal) after you complete sign-in.
