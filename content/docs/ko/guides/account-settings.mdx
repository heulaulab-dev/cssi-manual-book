# 계정 설정

## 프로필

프로필 탭에서는 개인 정보를 관리할 수 있습니다.

### 프로필 편집

1. **프로필 편집** 버튼을 클릭합니다
2. 필요에 따라 **이름**, **성** 또는 **기본 이메일**을 업데이트합니다
3. 변경 사항을 적용하려면 **변경사항 저장**을, 폐기하려면 **취소**를 클릭합니다

### 사용자 이름

사용자 이름은 참고용으로 표시되지만 이 인터페이스를 통해 변경할 수 없습니다. 관리자가 관리합니다.

## 보안

보안 탭에서는 비밀번호를 변경할 수 있습니다.

### 비밀번호 변경

1. **현재 비밀번호**를 입력합니다
2. **새 비밀번호**(8자 이상)를 입력합니다
3. **새 비밀번호 확인**에 새 비밀번호를 다시 입력하여 일치하는지 확인합니다
4. **비밀번호 변경**을 클릭합니다

## 세션

세션 탭에서는 로그인된 위치를 확인하고 활성 세션을 관리할 수 있습니다.

### 현재 세션

현재 세션은 항상 최상단에 표시됩니다. 다음 정보를 표시합니다:

- **장치** — 사용 중인 기기
- **브라우저** — 웹 브라우저
- **IP 주소** — 네트워크 주소
- **접속 중** — 현재 세션이 열려 있는 시간

### 기타 세션

다른 기기에서 로그인한 경우 **기타 세션** 아래에 표시됩니다. 각 세션에서 다음을 확인할 수 있습니다:

- **장치** — 기기 이름
- **IP 주소** — 네트워크 주소

### 세션 관리

- 다른 세션 옆의 **해지**를 클릭하여 해당 기기로 로그아웃합니다
- **다른 모든 세션 로그아웃**을 클릭하여 현재 세션을 제외한 모든 세션을 해지합니다

계정이 낯선 기기에서 접근되었을 가능성이 있는 경우에 유용합니다.

## 기본 설정

기본 설정 탭에서는 경험을 사용자 정의할 수 있습니다.

### 테마 모드

애플리케이션의 외관을 선택합니다:

| 테마 | 설명 |
|---|---|
| **다크** | 어두운 배경에 밝은 텍스트 |
| **라이트** | 밝은 배경에 어두운 텍스트 |
| **클래식 다크** | 더 어둡고 높은 대비의 테마 |
| **시스템** | 컴퓨터의 테마 설정에 자동으로 맞춤 |

### 사이드바 동작

왼쪽 사이드바의 동작 방식을 선택합니다:

| 동작 | 설명 |
|---|---|
| **확장됨** | 사이드바가 항상 열려 있습니다 |
| **축소됨** | 사이드바가 최소화됩니다; 클릭하여 확장 |
| **호버 시 확장** | 마우스를 가장자리로 움직일 때 사이드바가 확장됩니다 |

### 알림 기본 설정

받는 알림 유형을 제어합니다:

| 설정 | 설명 |
|---|---|
| **이메일 알림** | 이메일을 통해 알림 받기 |
| **푸시 알림** | 브라우저 푸시 알림 받기 |
| **SMS 알림** | 문자 메시지를 통해 알림 받기 |

옆에 있는 스위치를 사용하여 각 설정을 켜거나 끌 수 있습니다.
