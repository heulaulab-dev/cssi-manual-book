# 알림

모든 CSSI 애플리케이션에는 알림 페이지가 제공되며, 여기에서 알림을 보고, 필터링하고, 관리할 수 있습니다. 모든 페이지의 오른쪽 상단에 있는 **알림 종** 아이콘을 클릭하거나 사이드바에서 알림 페이지로 이동하여 접근할 수 있습니다.

## 알림 카테고리

알림은 페이지 상단의 필터 버튼을 통해 접근할 수 있는 카테고리로 구성됩니다:

| 필터 | 설명 |
|---|---|
| **전체** | 모든 카테고리에서 모든 알림 표시 |
| **미확인** | 아직 읽지 않은 알림만 표시 |
| **공지사항** | 시스템 및 인트라넷 공지사항 |
| **메이션** | 귀하가 언급된 알림 |
| **업데이트** | 상태 변경 및 활동 업데이트 |
| **액션** | 주의가 필요하거나 응답이 필요한 항목 |

각 필터 버튼은 읽지 않은 알림 수 배지를 표시하여 각 카테고리의 미확인 알림 수를 한눈에 확인할 수 있습니다.

## 알림 읽기

각 알림은 다음을 표시합니다:

- **제목** — 사건에 대한 간략한 설명
- **시간** — 알림이 생성된 시각
- **카테고리 배지** — 알림이 속한 카테고리
- **읽음/안 읽음 표시** — 미확인 알림은 강조 표시됩니다

알림을 클릭하여 전체 세부 정보를 보고 사용 가능한 작업을 수행할 수 있습니다.

## 알림 관리

모든 알림의 **세 점 메뉴**를 클릭하여 추가 작업에 접근합니다:

| 작업 | 설명 |
|---|---|
| **읽음으로 표시** | 단일 알림을 읽음으로 표시 (미확인 알림에만 사용 가능) |
| **1시간 동안 무시** | 알림을 임시로 숨깁니다; 1시간 후 다시 나타납니다 |
| **삭제** | 알림을 영구적으로 제거합니다 |
