# 공통 UI 패턴

모든 CSSI 애플리케이션은 일관된 인터페이스 패턴을 공유합니다. 이 가이드는 시스템 전반에서 마주치는 공통 요소를 다룹니다.

## 로딩 상태

애플리케이션이 데이터를 로드할 때 다음을 볼 수 있습니다:

- **스켈레톤 플레이스홀더** — 로딩 전에 콘텐츠의 대략적인 레이아웃을 보여주는 회색 애니메이션 플레이스홀더
- **스피너** — 특정 작업(저장 또는 제출 등)이 진행 중인 동안 표시되는 회전 표시기

이 패턴들은 데이터가 아직 나타나지 않더라도 시스템이 작동 중임을 항상 알 수 있도록 합니다.

## 에러 상태

문제가 발생하면 CSSI 애플리케이션은 일관된 에러 패턴을 표시합니다:

- **에러 경고** — 실패한 내용에 대한 메시지를 포함한 빨간색 배너
- **재시도 버튼** — 작업을 다시 시도하려면 **재시도**를 클릭합니다

## 빈 상태

페이지나 섹션에 표시할 데이터가 없을 때 다음이 있는 빈 상태를 봅니다:

- 콘텐츠 유형을 나타내는 아이콘
- 데이터가 없음을 설명하는 제목
- 제안 사항이 포함된 선택적 설명(예: "다른 필터를 시도")
- 새 항목을 생성 또는 추가하기 위한 선택적 작업 버튼

## 404 Not Found

존재하지 않는 페이지로 이동하면 친근한 404 페이지가 표시됩니다:

- **제목** — "찾으시는 페이지를 찾을 수 없습니다."
- **보조 텍스트** — "하지만 KB Valbury에서는 예기치 않은 우회로도 반드시 어디론가 이끕니다."
- **대시보드로 돌아가기** 버튼 — 애플리케이션 대시바로 돌아갑니다

## 토스트 알림

토스트 알림은 작업 확인이나 결과 보고를 위해 화면 오른쪽 상단에 나타납니다:

| 유형 | 모양새 | 표시 시기 |
|---|---|---|
| **성공** | 녹색 배경 | 작업이 성공적으로 완료된 경우 |
| **에러** | 빨간색 배경 | 작업이 실패한 경우 |
| **정보** | 파란색 배경 | 정보성 메시지 |
| **경고** | 노란색 배경 | 주의나 관심이 필요한 경우 |

토스트 알림은 몇 초 후 자동으로 사라집니다.

## 테이블 및 데이터 목록

데이터는 다음 공통 기능을 가진 테이블에 표시됩니다:

- **검색** — 텍스트로 행을 필터링하려면 검색 상자에 입력합니다
- **필터** — 드롭다운 선택기를 사용하여 상태, 유형, 날짜 범위 또는 기타 기준을 narrowly합니다
- **정렬** — 데이터가 오름차순 또는 내림차순으로 정렬되도록 열 헤더를 클릭합니다
- **페이지네이션** — **이전** 및 **다음** 버튼을 사용하여 결과 페이지 사이를 이동합니다
- **검색 결과 없음** — 필터와 일치하는 결과가 없을 때 빈 상태 메시지가 표시됩니다

## 확인 대화상자

- 발생할 일에 대한 명확한 제목

- 취소를 위한 **취소** 버튼
