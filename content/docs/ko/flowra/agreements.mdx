# 계약서

계약서는 Flowra의 계정 개설 워크플로우의 핵심 부분입니다. 고객과 회사가 계정 관계를 설정하기 위해 서명하는 공식 문서를 나타냅니다.

## 계약서란

- **계정 관계 공식화** — 계약서는 고객과 회사 간 약관을 문서화합니다
- **서명 상태 추적** — 어떤 계약서가 서명되었는지, 어떤 것이 대기 중인지 모니터링
- **디지털 카드 서명과 통합** — 계약서는 전자 서명을 위해 DCS 시스템을 통해 처리될 수 있습니다

## 워크플로우에서의 계약서 위치

계약서는 일반적으로 계정 개설 과정의 일부로 생성됩니다. 계정 신청이 생성되고 워크플로우를 진행하면, 관련 계약서가 검토 및 서명을 위해 준비됩니다.

계약서 워크플로우는 일반적으로 다음 단계를 따릅니다:

1. **생성** — 계정 세부 정보에 따라 계약서 생성
2. **검토** — 직원이 정확성과 완전성을 위해 계약서 검토
3. **승인** — 서명을 위해 계약서 승인
4. **서명** — 고객이 계약서 서명(대면 또는 DCS를 통해)
5. **완료** — 서명된 계약서가 제출되고 계정이 활성화됩니다

## 계약서 상태

| 상태 | 설명 |
|---|---|
| **초안** | 계약서가 준비되거나 편집 중입니다 |
| **검토 대기** | 허가된 직원 검토를 기다리고 있습니다 |
| **승인 대기** | 검토가 완료되었고 최종 승인을 기다리고 있습니다 |
| **승인됨** | 서명을 위해 승인된 계약서 |
| **서명됨** | 고객이 서명한 계약서 |
| **무효** | 취소되거나 무효화된 계약서 |

## 계약서 생성

계약서는 일반적으로 ���정 신청이 적절한 단계로 진행될 때 자동으로 생성됩니다. 일부 경우에는 수동으로 계약서를 시작하거나 재생성해야 할 수도 있습니다.

계약서를 생성하거나 보려면:

1. 계정 개설 섹션에서 관련 계정을 엽니다
2. 계약서 또는 문서 섹션으로 이동
3. 계약을 생성하거나 검토하라는 안내를 따릅니다

## 계약서 검토

계약서를 승인하기 전에 정확성을 위해 검토해야 합니다:

1. 계정 세부에서 계약서를 엽니다
2. 모든 필드와 약관이 정확한지 검토
3. 변경이 필요한 경우 계약서를 수정을 위해 반환
4. 계약서가 정확한 경우 승인으로 진행

## 계약서 승인

검토가 완료되면 계약서를 서명을 위해 승인할 수 있습니다:

1. 모든 세부 정보가 정확한지 확인
2. 계약서를 승인 상태로 이동하려면 **승인** 클릭
3. 이제 계약서가 고객 서명을 위해 준비됩니다

## 계약서 거부 또는 무효화

계약서에 오류가 있거나 더 이상 유효하지 않은 경우:

- **거부** — 수정해야 할 내용을 설명하는 코멘트와 함께 계약서를 수정을 위해 반환
