## 작업 섹션

작업은 확장 가능한 섹션으로 표시됩니다. 각 작업은 다음을 표시합니다:

- **작업 이름**
- **파트 수** — 작업 내 파트 수
- **항목 수** — 모든 파트의 체크리스트 항목 수

### 작업 이름 변경

1. 작업 행의 **이름 변경** 버튼(연필 아이콘) 클릭
2. 인라인 편집기에서 작업 이름 편집
3. 확인하려면 **Enter**를 누르거나 **저장** 클릭
4. 폐기하려면 **Escape**를 누르거나 **취소** 클릭

### 작업 삭제

1. 작업 행의 **삭제** 버튼(휴지통 아이콘) 클릭
2. 결과를 설명하는 확인 대화상자가 나타납니다
3. 확인하려면 **삭제**를, 중단하려면 **취소**를 클릭

<Callout type="warning">
  작업을 삭제하면 모든 파트와 체크리스트 항목이 제거됩니다. 해당 작업에 참조된 기존 제출에 영향이 있을 수 있습니다.
</Callout>

## 파트 섹션

각 작업 내에서, 파트는 중첩된 확장 가능한 섹션으로 표시됩니다. 각 파트는 다음을 표시합니다:

- **파트 이름**
- **체크리스트 항목 수**

### 파트 추가

1. 작업 섹션 확장
2. 확장된 작업 하단의 **파트 추가** 인라인 양식 클릭
3. **파트 이름** 필드에 파트 이름 입력
4. **파트 추가** 클릭

### 파트 이름 변경

1. 파트 행의 **이름 변경** 버튼(연필 아이콘) 클릭
2. 인라인 편집기에서 파트 이름 편집
3. 확인하려면 **Enter**를 누르거나 **저장** 클릭

### 파트 삭제

1. 파트 행의 **삭제** 버튼(휴지통 아이콘) 클릭
2. 확인 대화상자가 나타납니다
3. 확인하려면 **삭제**를, 중단하려면 **취소**를 클릭

## 체크리스트 항목 테이블

확장된 각 파트 내에서, 체크리스트 항목은 테이블로 표시됩니다:

| 열 | 설명 |
|---|---|
| **#** | 순차적 항목 번호 |
| **체크리스트 항목** | 체크리스트 항목의 ���름 |
| **순서** | 정렬 순서 번호 |
| **작업** | 이름 변경 및 삭제 버튼 |

### 체크리스트 항목 추가

1. 파트 섹션 확장
2. 확장된 파트 하단의 **항목 추가** 양식 사용
3. **체크리스트 항목** 필드에 항목 이름 입력
4. **항목 추가** 클릭

### 체크리스트 항목 이름 변경

1. 항목 행의 **이름 변경** 버튼(연필 아이콘) 클릭
