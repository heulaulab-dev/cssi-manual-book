# Daily Operation

Daily Operation은 CSSI 에코시스템 내 운영 체크리스트 작업 공간입니다. 매일의 작업 추적, 체크리스트 제출, 승인 워크플로우 및 운영 팀을 위한 역사적 보고를 지원합니다.

## 이 애플리케이션이란

Daily Operation은 팀이 체크리스트 기반 워크플로우를 통해 일상 운영 작업을 관리할 수 있는 구조화된 환경을 제공합니다. 전체 수명 주기를 지원합니다: 체크리스트 완료, 검토를 위해 제출, 제출 승인 또는 거부, 역사적 기록 검토.

## 시작하기

- **매일 체크리스트 완료** — 체크리스트 항목을 완료 표시, 코멘트 추가 및 수행된 작업 기록
- **승인을 위해 제출** — 완료된 체크리스트 일부를 감독자에게 검토를 위해 보내기
- **제출 승인 또는 거부** — 팀으로부터의 대기 중인 체크리스트 제출 검토 및 작업
- **이력 탐색** — 모든 사업 날짜에 대해 승인된 체크리스트 기록 보기
- **체크리스트 구성** — 작업, 파트 및 체크리스트 항목 생성 및 관리(권한 있는 사용자만)

## 핵심 개념

- **작업** — 관련된 운영 작업의 상위 그룹(예: "장 마감 처리")
- **파트** — 작업 내의 하위 그룹으로, 특정 체크리스트 항목에 대한 책임을 맡은 팀 또는 섹션을 나타냄
- **체크리스트 항목** — 완료 표시해야 하는 파트 내 개별 항목
- **사업 날짜** — 체크리스트가 추적되는 운영 날짜

## 부서

Daily Operation은 부서별로 구성되어 있습니다. **IT 부서**가 현재 활성화되어 있으며, 추가 부서(결제, 리스크 관리)는 향후 릴리스에 예정입니다.
