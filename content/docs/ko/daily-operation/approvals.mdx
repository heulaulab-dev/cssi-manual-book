## 사업 날짜 선택기

도구 모음의 **사업 날짜** 선택기를 사용하여 검토할 날짜를 선택합니다. 제출 목록이 선택한 날짜에 맞게 업데이트됩니다.

## 요약 막대

요약 막대는 선택한 날짜에 대한 네 가지 지표를 표시합니다:

| 지표 | 설명 |
|---|---|
| **대기 중** | 검토 대기 중인 제출 ��� |
| **승인됨** | 오늘까지 승인된 제출 수 |
| **거부됨** | 오늘까지 거부된 제출 수 |
| **총계** | 날짜의 총 제출 수 |

## 필터 컨트롤

제출 테이블 상단의 필터 컨트롤을 사용하여 결과를 좁힐 수 있습니다:

| 필터 | 설명 |
|---|---|
| **날짜** | 사업 날짜로 제출 필터링 |
| **상태** | 제출 상태(대기, 승인)로 필터 |

**검색** 상자를 사용하여 아이템 라벨로 제출을 찾을 수도 있습니다.

## 승인 대기열 테이블

제출 테이블은 각 대기 중 또는 승인된 제출을 다음 열과 함께 표시합니다:

| 열 | 설명 |
|---|---|
| **작업** | 제출이 속한 작업 이름 |
| **파트** | 파트 이름 |
| **상태** | 현재 상태 배지(대기, 승인) |
| **제출자** | 체크리스트를 제출한 사람 |
| **제출 시각** | 제출이 이루어진 시각 |
| **작업** | 대기 중인 항목에 대한 승인 및 거부 버튼 |

### 제출 승인

1. 테이블에서 대기 중인 제출을 찾습니다
2. **작업** 열에서 **승인** 버튼을 클릭합니다
3. 제출 상태가 승인된 것으로 변경됩니다

### 제출 거부

1. 테이블에서 대기 중인 제출을 찾습니다
2. **작업** 열에서 **거부** 버튼을 클릭합니다
3. 거부 대화상자가 나타나 이유를 요청합니다
4. **이유** 텍스트 영역에 거부 이유를 입력합니다
5. 확인하려면 **거부**를, 중단하려면 **취소**를 클릭합니다

## 제출 세부 정보 보기

제출 테이블의 행을 클릭하면 세부 패널이 열립니다. 세부 패널에는 다음이 표시됩니다:

- 작업 및 파트 이름
- 제출 상태
- 사업 날짜
- 제출자 및 제출 시각
- 승인자 및 승인 시각(해당되는 경우)
- 모든 항목, 완료 상태, 코멘트 및 수행된 작업이 포함된 완전한 체크리스트 테이블

## 빈 상태
