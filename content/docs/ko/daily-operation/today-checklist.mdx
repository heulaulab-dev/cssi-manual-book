## 작업 섹션

작업은 확장 가능한 섹션으로 표시됩니다. 각 작업은 다음을 표시합니다:

- **작업 이름**과 순번
- 작업에 속한 파트 수를 나타내는 **파트 수** 배지
- **완료 진행률** — 백분율 및 항목 수

작업 왼쪽의 확장/축소 화살표를 클릭하여 파트를 보여주거나 숨깁니다.

## 파트 섹션

각 작업 내에서, 파트는 중첩된 확장 가능한 섹션으로 표시됩니다. 각 파트는 다음을 표시합니다:

- **파트 이름**과 파트 번호(예: 1.1)
- **상태 배지** — 초안, 대기, 승인 또는 거부
- **완료 카운트** — 총 항목 대비 완료된 항목 수
- **저장 시간** — 파트가 마지막으로 저장되거나 제출된 시각

### 파트 상태

파트는 다음 네 가지 상태 중 하나를 가질 수 있습니다:

| 상태 | 의미 |
|---|---|
| **초안** | 아직 제출되지 않음; 아직 편집하고 저장 가능 |
| **대기** | 제출되어 승인 대기 중 |
| **승인됨** | 감독자가 승인함; 읽기 전용 |
| **거부됨** | 감독자가 거부함; 수정 필요 |

## 체크리스트 테이블

파트를 확장하면 다음 열이 있는 체크리스트 테이블이 표시됩니다:

| 열 | 설명 |
|---|---|
| **#** | 순차적 항목 번호 |
| **체크리스트 항목** | 체크리스트 항목의 이름 |
| **완료** | 항목을 완료 또는 미완료로 표시하는 체크박스 |
| **코멘트** | 코멘트 추가를 위한 선택적 텍스트 필드 |
| **수행된 작업** | 수행된 작업을 기록하기 위한 선택적 텍스트 필드 |

### 체크리스트 항목 완료

1. 작업 섹션을 이름 또는 화살표를 클릭하여 확장
2. 작업할 파트를 확장
3. 각 체크리스트 항목에 대해 **완료** 체크박스를 클릭하여 완료 표시
4. 선택적으로 각 항목에 대해 **코멘트** 또는 **수행된 작업** 추가

## 저장 및 제출

파트의 체크리스트 항목을 완료하면 진행 상황을 저장하거나 승인을 위해 제출할 수 있습니다.

### 파트 저장

**파트 저장**을 클릭하여 제출하지 않고 진행 상황을 저장합니다. 아직 제출할 준비가 되지 않았을 때(예: 완료해야 할 항목이 남아있는 경우) 사용합니다. 파트는 초안 상태로 유지됩니다.

### 파트 제출 / 재제출

**파트 제출**을 클릭하여 완료된 파트를 감독자에게 승인 위해 보냅니다. 이 버튼은 다음 조건에서 사용 가능합니다:

- 파트의 모든 체크리스트 항목이 완료로 표시됨
- 파트가 적어도 한 번 저장됨

파트가 이전에 거부된 경우, 버튼이 **재제출**로 변경됩니다. 체크리스트 테이블 위의 빨간색 경고 배너에서 거부 사유를 검토할 수 있습니다.

### 읽기 전용 파트

대기 중 또는 승인된 상태의 파트는 읽기 전용입니다. 체크리스트 테이블은 제출된 값을 고정 텍스트로 표시하며, 체크박스와 텍스트 필드가 비활성화됩니다. 파트 옆에 **읽기 전용** 배지가 나타납니다.

## 빈 상태

선택한 날짜에 구성된 체크리스트 작업이 없으면, 사용 가능한 작업이 없다는 메시지가 표시됩니다. 예약된 운영이 없는 날짜에는 이것이 정상입니다.

<Callout type="info">
  체크리스트는 부서와 역할별로 구성되어 있기 때문에 다른 팀 구성원의 체크리스트와 다를 수 있습니다.
</Callout>
