# 알림

알림 페이지에서는 CSSI 시스템 전반의 알림을 보고, 필터링하고, 관리할 수 있습니다. 대시보드 오른쪽 상단에 있는 **알림 종** 아이콘을 클릭하거나, 직접 알림 페이지로 이동하여 접근합니다.

## 알림 카테고리

알림은 페이지 상단의 탭을 통해 접근할 수 있는 네 가지 카테고리로 구성됩니다:

| 탭 | 설명 |
|---|---|
| **전체** | 모든 카테고리의 모든 알림 표시 |
| **보안** | 로그인 활동 및 비밀번호 변경 등 계정 보안 관련 경고 |
| **환경** | 시스템 및 환경 관련 알림 |
| **기기** | 기기 및 활성 세션에 대한 알림 |

## 알림 읽기

각 알림은 다음을 표시합니다:

- **제목** — 사건에 대한 간략한 설명
- **시간** — 알림이 생성된 시각
- **카테고리 배지** — 알림이 속한 카테고리
- **읽음/안 읽음 표시** — 미확인 알림은 강조 표시됩니다

알림을 클릭하여 전체 세부 정보를 보고 사용 가능한 작업을 수행할 수 있습니다.

## 알림 읽음으로 표시

- 단일 클릭하여 알림을 읽음으로 표시합니다
- 필터 탭을 사용하여 특정 유형의 알림을 빠르게 찾습니다
- **전체** 탭을 사용하여 모든 알림을 한눈에 봅니다
