## 대시보드 인사말

대시보드를 처음 로드할 때, 현재 시간대에 따라 "안녕하세요, John님"과 같은 개인화된 인사말이 표시됩니다. 이 인사말은 페이지 상단에 나타납니다. 위젯 데이터를 새로 고치기 위해 오른쪽 상단에 **새로 고침** 버튼이 있습니다.

## Intranet 공지사항

Intranet 공지사항 위젯은 대시보드 상단에 나타나며, Portal을 떠나지 않고도 내부 및 관리 정보를 확인할 수 있습니다:

- 요약 뷰 — 가장 최근 공지사항만 표시됩니다
- 각 공지사항은 제목, 간략한 발췌문, 날짜 및 **새로운** 또는 **긴급** 배지를 표시합니다
- 공지사항을 클릭하여 Portal 내에서 전체 내용을 읽습니다
- 하단의 **전체 인트라넷 공지사항 보기** 링크를 사용하여 Intranet에서 완전한 목록을 엽니다

## 개발

개발 위젯에는 IT 개발 요청과 현재 상태에 대한 빠른 뷰가 표시됩니다:

- 위젯 상단의 카테고리 탭을 사용하여 상태로 필터링할 수 있습니다
- 각 항목은 요청 제목, 간단한 설명, 상태 배지 및 요청자 이름을 표시합니다
- 요청을 클릭하여 ITQM에서 더 많은 세부 정보를 봅니다

표시되는 상태 카테고리:

| 상태 | 설명 |
|---|---|
| 진행 중 | 작업이 활발히 진행 중입니다 |
| 승인 대기 | 요청자나 사업 부서로부터 승인을 기다리고 있습니다 |
| 할당 대기 | IT 개발자가 할당되기를 기다리고 있습니다 |
| IT 승인 대기 | 완료 후 IT 승인을 기다리고 있습니다 |
| 검증 대기 | 요청자의 검증을 기다리고 있습니다 |
| 수정 | 피드백에 따라 변경 중입니다 |
| 초안 | 아직 준비 중이며 제출되지 않았습니다 |
| 완료 | 완료되어 종료되었습니다 |

## 매일의 체크리스트

매일의 체크리스트 위젯에는 사용자에게 관련된 운영 체크리스트 활동을 빠르게 보여줍니다:

- 각 항목은 작업 이름, 부서/팀 이름, 확인된 항목 수, 상태 배지 및 제출자를 표시합니다
- 상태별로 필터링하기 위한 카테고리 탭을 사용합니다: **전체**, **대기**, **승인됨**, **거부됨**
- 체크리스트 항목을 클릭하여 Daily Operation에서 세부 정보를 보고 작업을 수행합니다

## 주식

주식 위젯은 Portal 대시보드에서 바로 시장 요약을 제공합니다:

- 위젯 상단의 검색 상자를 사용하여 이름이나 코드로 주식을 찾고 선택합니다
- 위젯은 현재 가격, 가격 변동 및 가격 이력을 보여주는 차트를 표시합니다
- 시간 범위 선택기를 사용하여 다른 기간을 봅니다 (1D, 5D, 1M, 3M, 1Y)
- **주식 열기**를 클릭하여 CRM에서 완전한 주식 관리 인터페이스를 엽니다

표시되는 요소:

- 주식 식별자 및 이름(검색을 통해 선택됨)
- 인도네시아 루피아 단위의 현재 가격
- 색상에 따라 코드된 가격 변동(절대값 및 백분율, 상승은 녹색, 하락은 빨간색)
- 날짜와 가격을 보여주는 대화형 툴팁이 있는 가격 차트
- 시간 범위 선택기

## 순위

순위 위젯은 포트폴리오 및 거래 성과에 대한 요약 순위 뷰를 제공합니다:

- 위젯 헤더의 선택기를 사용하여 **P/L 순위**와 **거래 순위** 간 전환합니다
- **P/L 순위**는 이익과 손실 성과에 따라 상위 5개 주식을 보여줍니다
- **거래 순위**는 거래 활동에 따라 상위 5개 주식을 보여줍니다

### P/L 순위 열

| 열 | 설명 |
|---|---|
| 순위 | 순위에서의 위치 |
| 주식 | 주식 코드 및 이름 |
| 평균 가격 | 평균 거래 가격 |
| 종가 | 최신 마감 가격 |
| 일일 P/L 금액 | 당일 이익 또는 손실 |
| 주식 가치 | 총 시장 가치 |
| 총 잔액 | 계정 잔액 |
| P/L 비율 | 백분율 수익률(색상 코드) |

### 거래 순위 열

| 열 | 설명 |
|---|---|
| 순위 | 순위에서의 위치 |
| 주식 | 주식 코드 및 이름 |
| 시가 | 기간의 시작 가격 |
| 종가 | 기간의 마감 가격 |
| 가격 변동 | 절대 가격 변동 |
| 총 수량 | 거래된 주식 수 |
| 총 가치 | 총 거래 가치 |
| 총 거래량 | 거래량 |
| 변동률 % | 백분율 변동(색상 코드) |

**P/L 순위 모두 보기** 또는 **거래 순위 모두 보기**를 클릭하여 CRM에서 완전한 순위를 엽니다.
