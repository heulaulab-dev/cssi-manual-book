# Portal

포털은 CSSI 애플리케이션 에코시스템의 주요 진입점입니다. 로그인 후 사용자는 대시보드로 이동하여 CSSI 전체의 중요한 정보를 통합적으로 확인할 수 있습니다.

## Portal이란

- **시작점** — 모든 사용자는 로그인 후 여기로 이동합니다
- **통합 뷰** — Portal은 CSSI 전체 애플리케이션의 요약을 표시합니다
- **빠른 탐색** — 한 곳에서 모든 CSSI 애플리케이션에 접근할 수 있습니다
- **중요 공지** — 주요 공지사항이 눈에 띄게 표시됩니다
