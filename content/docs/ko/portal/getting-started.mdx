# 시작하기

Portal에서 적응하기 위해 다음 단계를 따르세요.

## 로그인하고 Portal에 진입하기

<Steps>
  <Step>

### 단계 1 — 로그인

인증 정보를 입력하고 CSSI에 로그인합니다. 모든 사용자는 성공적으로 로그인하면 Portal로 이동됩니다.

> **스크린샷 플레이스홀더**
>
> Add screenshot: Login success leading to the Portal dashboard.

  </Step>
  <Step>

### 단계 2 — 대시보드 확인

Portal 대시보드에는 다양한 CSSI 애플리케이션에서의 요약을 보여주는 위젯이 표시됩니다. 표시되는 위젯은 부서와 사용 가능한 정보에 따라 다를 수 있습니다.

> **스크린샷 플레이스홀더**
>
> Add screenshot: Portal Dashboard showing visible widgets for one user/division.

  </Step>
  <Step>

### 단계 3 — 중요 공지사항 확인

처음 로그인할 때, 중요한 시스템 공지사항을 표시하는 팝업 창이 나타날 수 있습니다. 공지사항을 읽고 **이해했습니다**를 클릭하여 닫습니다. 이는 중요한 정보를 인지하고 있는지 확인합니다.

> **스크린샷 플레이스홀더**
>
> Add screenshot: Announcement modal showing an important notice with "I Understand" button.

  </Step>
  <Step>

### 단계 4 — 대시보드 위젯 확인

위젯을 클릭하여 자세한 내용을 보거나 관련 애플리케이션으로 이동합니다. 위젯은 관련 CSSI 애플리케이션에서의 요약을 제공합니다.

> **스크린샷 플레이스홀더**
>
> Add screenshot: Portal widget with a visible list or actionable status.

  </Step>
  <Step>

### 단계 5 — 관련 애플리케이션에서 계속하기

Portal은 시작점입니다. 주의가 필요한 항목을 파악하면, 관련 애플리케이션을 열어 워크플로우를 완료합니다. 상세한 워크플로우는 Portal이 아닌 애플리케이션에서 이루어집니다.

> **스크린샷 플레이스홀더**
>
> Add screenshot: Widget action or application shortcut leading into another CSSI application.

  </Step>
</Steps>

## 최초 설정

처음 로그인하는 경우, 비밀번호 변경을 요구받을 수 있습니다. 이는 계정을 보호하기 위한 보안 조치입니다.

<Steps>
  <Step>

### 단계 1 — 비밀번호 변경

처음 로그인할 때, 비밀번호 재설정 페이지로 리디렉션됩니다. 임시 비밀번호를 입력하고, 새 안전 비밀번호(8자 이상)를 선택한 후 확인합니다.

> **스크린샷 플레이스홀더**
>
> Add screenshot: First-time password reset form.

  </Step>
  <Step>

### 단계 2 — 대시보드로 계속하기

비밀번호 변경이 성공하면 Portal 대시바로 리디렉션됩니다.

  </Step>
</Steps>

## 다음 단계

- **대시보드** 위젯을 탐색하여 사용 가능한 정보를 확인합니다
- 대시보드 하단의 **애플리케이션** 섹션을 확인하여 다른 CSSI 앱에 접근합니다
- 오른쪽 상단의 이름을 클릭하여 **계정 설정**에 접근합니다
- **종 아이콘**을 클릭하여 알림을 확인합니다

<Callout type="info">
  대시보드는 특정 부서와 역할에서만 사용할 수 있는 일부 위젯이 있기 때문에
  다른 사용자의 대시보드와 다를 수 있습니다.
</Callout>

<Callout type="info">
  특정 애플리케이션이나 기능에 접근할 수 없는 경우, 적절한 권한을 요청하기 위해
  관리자에게 문의하세요.
</Callout>
