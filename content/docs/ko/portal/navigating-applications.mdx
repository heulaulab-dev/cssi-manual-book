# 애플리케이션 탐색

Portal은 CSSI의 시작점이며, 상세한 워크플로우는 관련 애플리케이션에서 이루어집니다. 이 가이드는 Portal과 다른 애플리케이션 간 이동 방법을 설명합니다.

## 상단 애플리케이션 탐색 사용

Portal의 상단 탐색 바에서는 다른 애플리케이션으로 전환할 수 있습니다. Portal에 있을 때, 다른 애플리케이션 이름을 클릭하면 새 탭에서 열립니다.

현재 표시되는 애플리케이션:

- Portal
- CRM
- Intranet
- FLOWRA
- ITQM
- Daily Operation

## 애플리케이션 섹션 사용

대시보드 하단의 애플리케이션 섹션은 사용 가능한 모든 CSSI 애플리케이션에 대한 카드를 제공합니다. 각 카드는 다음을 표시합니다:

- 애플리케이션 이름
- 간단한 설명
- **`앱 이름` 열기** 버튼

**열기** 버튼을 클릭하여 애플리케이션을 실행합니다.

## 대시보드 위젯 작업 사용

일부 대시보드 위젯은 다른 애플리케이션의 관련 워크플로트로 안내하는 작업 버튼을 제공합니다:

| 위젯 | 작업 | 이동 경로 |
|---|---|---|
| Intranet 공지사항 | **인트라넷 공지사항 모두 보기** | Intranet 애플리케이션 |
| 개발 | **개발 요청 추가** / **개발 모두 보기** | ITQM 애플리케이션 |
| 매일의 체크리스트 | **매일 체크리스트 추가** / **체크리스트 모두 보기** | Daily Operation 애플리케이션 |
| 주식 | **주식 열기** / **주식 모두 보기** | CRM 애플리케이션 |
| 순위 | **P/L 순위 열기** / **거래 순위 열기** | CRM 애플리케이션 |

## 알림 종 사용

페이지 오른쪽 상단에 있는 **알림 종** 아이콘을 클릭하여 알림을 봅니다. 여기에서 다음을 수행할 수 있습니다:

- 알림을 카테고리별로 필터링합니다 (전체, 보안, 환경, 기기)
- 알림을 읽음으로 표시합니다
- 각 알림의 소스로 이동합니다

## 계정 설정 사용

오른쪽 상단의 **프로필 아이콘 또는 이름**을 클릭하여 다음에 접근합니다:

- **계정** — 프로필, 보안 설정 및 기본 설정을 관리합니다
- **로그아웃** — Portal에서 로그아웃합니다
