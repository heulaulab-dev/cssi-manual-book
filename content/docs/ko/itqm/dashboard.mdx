## 인사말

대시보드를 로드할 때, 현재 시간대에 따른 개인화된 인사말을 봅니다. **새로 고침** 버튼을 사용하여 위젯 데이터를 새로 로드할 수 있습니다.

## KPI 카드

대시보드 상단에 상태별 개발 요청에 대한 빠른 요약을 제공하는 KPI 카드 행이 있습니다. 각 카드는 특정 상태의 수와 레이블을 표시합니다.

| 카드 | 설명 |
|---|---|
| 초안 | 아직 제출되지 않고 준비 중인 요청 |
| 승인 대기 | 요청자나 사업 부서로부터 승인을 기다리고 있는 요청 |
| 수정 | 피드백에 따라 수정 중인 요청 |
| IT 승인 대기 | 완료 후 IT 승인을 기다리고 있는 요청 |
| 할당 대기 | IT 개발자가 할당되기를 기다리고 있는 요청 |
| 진행 중 | 작업이 활발히 진행 중인 요청 |
| 검증 대기 | 요청자의 검증을 기다리고 있는 요청 |
| 완료 | 완료되어 종료된 요청 |

## 개발 수명 주기

개발 수명 주기 위젯은 모든 워크플로우 단계에 걸쳐 요청의 파이프라인을 시각화합니다. 초안부터 완료까지 수평 흐름을 보여주며, 각 단계의 요청 수를 표시합니다.

어디에 요청이 집중되어 있는지, 그리고 어느 단계에 병목 현상이 있는지 빠르게 이해할 수 있습니다.

## 다가오는 마감일

다가오는 마감일 위젯은 마감일이 다가오는 개발 요청을 나열합니다. 각 항목은 요청 제목, 할당된 사람 및 마감일을 표시합니다:

- 항목은 마감일이 가까운 순으로 정렬됩니다
- 지정일 초과 항목은 눈에 띄게 강조됩니다
- 요청을 클릭하여 완전한 세부 정보를 봅니다

## 팀 작업량

팀 작업량 위젯은 각 팀 구성원에게 할당된 작업의 분할을 보여줍니다. 현재 용량과 새 작업을 받을 수 있는 구성원을 파악하는 데 도움이 됩니다:

- 각 행은 팀 구성원의 이름과 상태별 활성 요청 수를 표시합니다
- 작업량은 상태별 색상 표시기로 시각화됩니다

## Intranet 공지사항

Intranet 공지사항 위젯은 담당 부서에 관련된 내부 공지사항을 표시합니다. 제목, 발췌문 및 날짜가 있는 가장 최근 공지사항을 보여줍니다:

- 공지사항을 클릭하여 전체 내용을 읽습니다

## 최근 완료

최근 완료 위젯은 최근에 완료된 개발 요청을 나열합니다. 완료 보고를 방문하지 않고도 완료된 작업을 볼 수 있습니다:

- 각 항목은 요청 제목, 시스템, 요청자 및 완료 날짜를 표시합니다

## 매일의 체크리스트

매일의 체크리스트 위젯은 매일 운영 체크리스트 활동에 대한 요약을 제공합니다. 각 항목은 체크리스트 이름, 상태 및 제출 세부 정보를 표시합니다:

- 상태별로 필터링하기 위한 카테고리 탭을 사용합니다: **전체**, **대기**, **승인**, **거부**
- 체크리스트 항목을 클릭하여 Daily Operation에서 세부 정보를 봅니다

## 상태 분해 차트

## 활동 추세 차트

활동 추세 차트는 시간 경과에 따른 개발 요청 활동을 보여줍니다. 선택한 기간 동안 생성되고 완료된 요청의 라인 또는 막대 차트를 표시합니다:

- 시간 범위 선택기를 사용하여 다른 기간을 봅니다
- 차트는 개발 활동의 추세를 식별하는 데 도움이 됩니다

## 대시보드에서 탐색하기

어떤 위젯에서도 항목을 클릭하여 관련 세부 페이지로 직접 이동할 수 있습니���. 왼쪽 사이드바를 사용하여 ITQM 섹션 간에도 이동할 수 있습니다:

- **요청 개발** — 요청 제출 및 관리
- **요청 수락** — 요청 검토 및 할당(IT 승인자 역할)
- **요청 승인** — 요청 승인 또는 거부(부서 승인자 역할)
- **완료 보고** — 완료된 작업 보기 및 검증
- **문제** — 목록 또는 칸반 뷰로 문제 추적
