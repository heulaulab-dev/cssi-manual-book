# 개발 요청

개발 요청은 초기 제출부터 승인, 할당 및 추적을 거쳐 IT 개발 작업의 완전한 수명 주기를 관리합니다. 워크플로우는 역할에 따라 세 가지 주요 뷰로 나뉩니다: **요청 개발**(제출자), **요청 수락**(IT 승인자), **요청 승인**(부서 승인자).

## 요청 워크플로우 개요

개발 요청은 다음 단계를 거칩니다:

1. **초안** — 생성되었지만 아직 제출되지 않음
2. **승인 대기** — 제출되어 부서 승인을 기다리고 있음
3. **수정** — 변경을 위해 다시 보내짐
4. **IT 승인 대기** — 승인되고 IT 승인을 기다리고 있음
5. **할당 대기** — 수락되었고 개발자를 할당받기를 기다리고 있음
6. **진행 중** — 작업이 활발히 수행 중임
7. **검증 대기** — 완료되어 요청자의 검증을 기다리고 있음
8. **완료** — 검증되어 종료됨

## 요청 개발

**요청 개발** 뷰는 제출자가 개발 요청을 생성, 관리 및 추적하는 곳입니다.

### 요청 테이블

테이블은 제출했거나 관련이 있는 모든 요청을 표시합니다. 각 행은 다음을 표시합니다:

| 열 | 설명 |
|---|---|
| 제목 | 요청 제목 |
| 유형 | 요청 카테고리(예: 기능, 버그 수정) |
| 시스템 | 대상 시스템 또는 애플리케이션 |
| 상태 | 현재 워크플로우 상태 |
| 제출됨 | 요청이 제출된 날짜와 시각 |
| 작업 | 요청에 대한 사용 가능한 작업 |

열 헤더를 사용하여 정렬하고 검색 바로 필터링합니다.

### 새 요청 생성

새 개발 요청을 제출하려면:

1. 요청 개발 페이지 오른쪽 상단의 **새 요청** 버튼 클릭
2. 대화상자의 필수 필드 채우기:
   - **제목** — 요청에 대한 명확한 제목
   - **요구사항** — 필요한 내용에 대한 상세 설명
   - **유형** — 드롭다운에서 요청 카테고리 선택
   - **시스템** — 드롭다운에서 대상 시스템 선택
   - **첨부 파일** — 선택적으로 지원 파일 첨부
3. 요청을 승인에 보내려면 **제출** 클릭

### 편집 및 재제출

요청이 **수정** 상태로 보내지면, 편집하고 재제출할 수 있습니다:

1. 테이블에서 요청 열기
2. **편집** 클릭하여 제목, 요구사항, 유형, 시스템 또는 첨부 파일 수정
3. 변경 사항을 검토하고 **재제출** 클릭하여 워크플로우로 다시 보냄

## 요청 수락

**요청 수락** 뷰는 IT 승인자가 도착한 요청을 검토하고 개발 작업을 할당하는 데 사용됩니다.

### 수락 테이블

테이블은 IT 승인을 받을 준비가 된 요청을 표시합니다. 각 행은 다음을 표시합니다:

| 열 | 설명 |
|---|---|
| 제목 | 요청 제목 |
| 유형 | 요청 카테고리 |
| 시스템 | 대상 시스템 |
| 요청자 | 요청을 제출한 사람 |
| 부서 승인자 | 승인한 부서 승인자 |
| 승인됨 | 부서 승인 날짜 |
| 상태 | 현재 워크플로우 상태 |
| 작업 | 요청에 대한 사용 가능한 작업 |

### 요청 수락

요청을 수락하려면:

1. 요청 행에서 **수락** 클릭
2. PIC(책임자)와 기한을 선택할 수 있는 할당 패널이 열림
3. 드롭다운에서 **PIC** 선택
4. 작업에 대한 **기한** 설정
5. 확인하려면 **할당** 클릭

### 요청 거부

요청을 거부하려면:

1. 요청 행에서 **거부** 클릭
2. 거부 대화상자가 열림
3. 거부 이유 입력
4. 요청자를 보낼 **제출** 클릭

| 제출됨 | 요청이 제출된 날짜와 시각 |
| 상태 | 현재 워크플로우 상태 |
| 작업 | 요청에 대한 사용 가능한 작업 |

### 요청 승인

요청을 승인하려면:

1. 요청 행에서 **승인** 클릭
2. 요청이 **IT 승인 대기** 상태로 이동
3. IT 승인자가 검토하고 작업을 할당하도록 알림

### 요청 거부

요청을 거부하려면:

1. 요청 행에서 **거부** 클릭
2. 거부 대화상자가 열림
3. 거부 이유 입력
4. 요청자를 **수정** 상태로 보내려면 **제출** 클릭

- 현재 상태 및 워크플로우 이력
- 할당된 PIC와 기한(할당된 경우)
