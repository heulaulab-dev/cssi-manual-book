# ITQM

ITQM은 CSSI 내 IT 품질 관리 애플리케이션입니다. 제출부터 승인, 할당, 구현 및 검증까지 개발 요청의 완전한 수명 주기를 관리합니다. 또한 문제 추적과 팀 작업량 관리를 제공합니다.

## ITQM이란

- **개발 요청 제출** — IT에 새 기능, 버그 수정 또는 시스템 개선 요청
- **요청 상태 추적** — 전체 워크플로우 단계를 통해 모든 요청을 따르기
- **승인 관리** — 적절한 승인 채널을 통해 요청 라우팅
- **작업 할당** — 기한과 함께 팀 구성원에게 개발 작업 할당
- **완료 검증** — 작업이 완료된 후 검토하고 검증하여 완료 표시
- **문제 추적** — 우선순위, 상태 및 할당과 함께 문제 기록 및 관리
- **작업 시각화** — 칸반 보드에서 팀 작업량과 진행 상황 보기

## 시작하기

- 개발 요청 생성, 편집 및 재제출
- IT 승인자로서 도착한 요청 수락 또는 거부
- 부서 승인자로서 요청 승인 또는 거부
- 개발자 및 기한을 받아들이는 요청에 할당
- 작업을 완료로 표시하고 완곡을 검증
- 우선순위와 상태로 문제 생성 및 관리
- 드래그 앤 드롭으로 칸반 보드에서 작업 항목 보기
- 요청 유형과 시스템 유형 구성
- 대시보드에서 작업량과 다가오는 마감일 모니터링

## 탐색

ITQM은 다음 주요 영역으로 구성되어 있습니다:

- **대시보드** — KPI, 작업량 및 다가오는 마감일이 있는 개인화된 개요
- **개발 요청** — 완전한 요청 수명 주기를 제출하고 관리
- **완료 보고** — 완료된 작업 보기 및 완료 검증 또는 재정의
- **문제** — 목록 뷰 또는 칸반 보드로 문제 추적
- **구성** — 요청 유형과 시스템 유형 관리(권한 있는 사용자만)
