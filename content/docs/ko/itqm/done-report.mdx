## 완료 보고 테이블

테이블은 완료로 표시된 모든 개발 요청을 표시합니다. 각 행은 다음을 표시합니다:

| 열 | 설명 |
|---|---|
| 제목 | 요청 제목 |
| 유형 | 요청 카테고리 |
| 시스템 | 대상 시스템 |
| 요청자 | 요청을 제출한 사람 |
| PIC | 할당된 개발자 |
| 기한 | 작업의 마감일 |
| 상태 | 현재 상태 |
| 지연 | 요청이 기한 후에 완료되었는지 |
| 등록됨 | 요청이 등록되었는지 |
| 작업 | 요청에 대한 사용 가능한 작업 |

열 헤더를 사용하여 정렬하고 검색바로 필터링합니다.

## 작업

역할과 요청 상태에 따라 다음 작업을 볼 수 있습니다:

### 완료로 표시

요청이 **진행 중** 또는 **검증 대기** 상태일 때, 완료로 표시할 수 있습니다:

1. 요청 행에서 **완료로 표시** 클릭
2. 요청이 **완료** 상태로 이동
3. 요청자가 완곡 검증을 받도록 알림

### 검증

요청이 **검증 대기** 상태일 때, 요청자가 완곡을 검증할 수 있습니다:

1. 요청 행에서 **검증** 클릭
2. 요청이 완료된 것으로 확정되고 종료됨
3. 요청이 영구적으로 **완료** 상태로 이동

### 완료 강제 종료

정상 워크플로우 외의 요청을 강제로 완료 상태로 이동해야 할 때:

1. 요청 행에서 **완료 강제 종료** 클릭
2. 검증 없이 요청이 강제로 종료됨

### 등록 토글

**등록 토글** 작업은 요청을 등록됨 또는 미등록으로 표시할 수 있습니다:

1. 요청 행에서 **등록 토글** 클릭
2. 등록 상태가 업데이트됨

등록은 완료된 요청이 시스템에 공식적으로 등록되었는지 추적하는 데 사용됩니다.

## 지연 표시

**지연** 열은 요청이 기한 후에 완료되었는지 보여줍니다. 이는 납기 지연을 식별하고 정시 완료율을 추적하는 데 도움이 됩니다:

- 지연된 요청은 시각적으로 강조됩니다
- 대시보드에도 다가오는 마감일 위젯에 지연 정보가 표시됩니다
