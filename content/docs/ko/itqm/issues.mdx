## 문제 목록

문제 목록은 테이블 형식으로 추적된 모든 문제를 표시합니다. 각 행은 다음을 표시합니다:

| 열 | 설명 |
|---|---|
| 키 | 고유 문제 식별자 |
| 제목 | 문제 제목 또는 요약 |
| 유형 | 문제 카테고리(예: 버그, 작업, 개선) |
| 우선순위 | 문제의 긴급성(예: 중요, 높음, 중간, 낮음) |
| 상태 | 현재 워크플로우 상태 |
| 할당된 사람 | 문제의 책임자 |
| 기한 | 문제가 해결되어야 하는 날짜 |
| 연결된 요청 | 이 문제에 연결된 개발 요청 |
| 작업 | 문제에 대한 사용 가능한 작업 |

열 헤더를 사용하여 정렬하고 검색바로 필터링합니다.

### 새 문제 생성

새 문제를 생성하려면:

1. 문제 페이지 오른쪽 상단의 **새 문제** 버튼 클릭
2. 대화상자의 필수 필드 채우기:
   - **제목** — 문제에 대한 명확한 요약
   - **설명** — 문제에 대한 상세 정보
   - **유형** — 드롭다운에서 문제 카테고리 선택
   - **우선순위** — 드롭다운에서 긴급성 수준 선택
   - **할당된 사람** — 선택적으로 누군가에게 할당
   - **기한** — 선택적으로 마감일 설정
   - **연결된 요청** — 선택적으로 기존 개발 요청에 연결
3. **제출** 클릭하여 문제 생성

### 문제 작업

문제 상태와 역할에 따라 다음 작업을 볼 수 있습니다:

- **편집** — 문제 세부 정보 수정
- **할당** — 할당된 사람 변경
- **종료** — 문제가 해결됨으로 표시
- **다시 열기** — 종료된 문제를 다시 열기

### 문제 세부 정보

목록에서 문제를 클릭하면 완전한 세부 정보 보기가 열립니다. 여기에는 다음이 표시됩니다:

- 제목, 설명 및 유형 정보
- 우선순위와 상태
- 할당된 사람과 기한
- 연결된 개발 요청(있는 경우)
- 활동 이력 및 코멘트

## 칸반 보드

칸반 보드는 상태별로 조직된 시각적, 카드 기반 뷰를 제공합니다. 워크플로우 단계를 나타내는 다섯 개의 열을 사용합니다.

### 보드 열

| 열 | 설명 |
|---|---|
| 백로그 | 생성되었지만 아직 우선순위가 지정되지 않은 문제 |
| 준비 | 작업하기 준비되고 사용 가능한 문제 |
| 진행 중 | 활발히 작업 중인 문제 |
| 검토 중 | 완료되어 검토를 기다리는 문제 |
| 완료 | 완료되어 종료된 문제 |

### 문제 이동

다른 상태로 문제를 이동하려면:

1. 문제 카드에서 클릭하고_HOLD
2. 대상 열로 카드를 드래그
3. 새로운 열에서 놓기
4. 문제 상태가 자동으로 업데이트됨

### 보드에서 문제 생성

칸반 보드에서 새 문제를 직접 생성할 수도 있습니다:

1. **새 문제** 버튼 클릭
2. 대화상자에서 문제 세부 정보 채우기
3. 문제가 생성되어 상태에 따라 적절한 열에 배치됨

### 보드 필터링

보드 상단의 필터 컨트롤을 사용하여 표시되는 문제를 좁힐 수 있습니다:

- 할당된 사람으로 필터하여 한 사람의 작업 보기
- 우선순위로 필터하여 중요한 항목에 집중
- 유형으로 필터하여 특정 카테고리의 문제 보기

## 목록 뷰 vs. 칸반 보드

| 사용할 때 | 권장 뷰 |
|---|---|
| 상세 필터링 및 정렬 | 문제 목록 |
| 시각적 워크플로우 관리 | 칸반 보드 |
| 많은 문제에 대한 대량 작업 | 문제 목록 |
| 드래그 앤 드롭으로 빠른 상태 변경 | 칸반 보드 |
| 인라인 문제 세부 정보 보기 | 문제 목록 |

페이지 상단의 뷰 전환 버튼을 사용하여 목록 뷰와 칸반 보드 간 전환할 수 있습니다.
