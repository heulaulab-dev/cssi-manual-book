# 시작하기

이 안내서는 ITQM을 열고 개발 요청과 문제로 작업하기 시작할 수 있도록 레이아웃을 이해하는 데 도움이 됩니다.

<Steps>
  <Step>

### 단계 1 — ITQM 열기

Portal 대시보드 또는 상단 애플리케이션 탐색 바에서 ITQM에 접근합니다.

### 단계 2 — 작업 공간 이해하기

ITQM이 열리면 시작 페이지로 **대시보드**를 봅니다. 대시보드에는 역할에 관련된 KPI 카드, 작업량 정보 및 다가오는 마감일이 표시됩니다.

왼쪽 사이드바는 모든 ITQM 섹션에 대한 탐색을 제공합니다:

- **대시보드** — 지표와 활동이 있는 개요
- **요청 개발** — 개발 요청 제출 및 추적
- **요청 수락** — 도착한 요청 검토 및 할당(IT 승인자 역할)
- **요청 승인** — 요청 승인 또는 거부(부서 승인자 역할)
- **완료 보고** — 완료된 작업 보기 및 완료 검증
- **문제** — 목록 또는 칸반 뷰로 문제 추적
- **구성** — 요청 및 시스템 유형 관리(권한 있는 사용자만)

### 단계 3 — 대시보드에서 시작하기

현재 작업량을 이해하기 위해 **대시보드**를 확인합니다:

- 상단의 **KPI 카드**로 상태별 요청 수 요약 확인
- **개발 수명 주기** 위젯으로 전체 파이프라인 보기
- **다가오는 마감일**을 검토하여 곧 주의가 필요한 항목 확인
- **팀 작업량** 위젯을 통해 누가 무엇을 작업 중인지 확인

대시보드에서 사이드바를 사용하여 모든 섹션으로 이동할 수 있습니다.
