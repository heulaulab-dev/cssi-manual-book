## 관리자 패널 접근하기

관리자 패널은 관리자 권한이 있는 경우 사이드바에서 접근할 수 있습니다. 관리 작업 공간에 접근하려면 사이드바에서 **관리**로 이동합니다.

관리 접근 권한이 없으면 사이드바에 관리 섹션이 표시되지 않습니다.

## 관리자 대시보드

관리자 대���보드에는 시스템의 운영 개요가 표시됩니다:

### 사용자 개요

사용자 계정 요약 지표를 표시합니다:

- **총계** — 시스템의 모든 사용자 계정
- **활성** — 현재 활성인 사용자 계정(녹색 표시와 함께)
- **비활성** — 비활성 사용자 계정

### 활동 개요

지난 24시간에 기록된 감사 이벤트 수를 표시하여 최근 관리 활동에 대한 빠른 뷰를 제공합니다.

### 빠른 작업

일반적인 관리 작업에 대한 버튼:

- **사용자 생성** — 새 사용자를 추가하기 위해 사용자 페이지 열기
- **역할 및 권한** — 역할 할당 관리 열기
- **새 공지사항** — 시스템 공지사항 페이지 열기
- **감사 로그 보기** — 활동 검토를 위해 감사 로그 페이지 열기

### 최근 활동

가장 최근의 관리 작업 피드를 표시합니다:

- 수행된 작업
- 엔터티 유형(사용자, 역할, 권한, 로그인, 공지사항)
- 작업을 수행한 사람
- 발생 시각(상대적 시간 표시와 함께)

**전체 보기**를 클릭하여 완전한 감사 로그 페이지를 엽니다.

### 사용자 보기

사용자 테이블은 관련 정보와 함께 모든 사용자 계정을 표시합니다. 검색바와 필터를 사용하여 특정 사용자를 찾습니다.

### 새 사용자 생성

1. **관리 > 사용자**로 이동
2. 새 사용자 생성 버튼 클릭
3. 필수 사용자 정보 채우기
4. 새 사용자 계정 저장

### 사용자 계정 관리

사용자 페이지에서 다음을 수행할 수 있습니다:

- 사용자 세부 정보 보기
- 사용자 정보 편집
- 사용자 계정 활성화 또는 비활성화
- 사용자에게 역할 할당

### 역할 보기

역할 테이블은 이름과 설명이 있는 모든 정의된 역할을 표시합니다.

### 역할 관리

역할 페이지에서 다음을 수행할 수 있습니다:

- 역할 세부 정보와 할당된 권한 보기
- 역할 이름과 설명 편집
- 역할에서 권한 할당 또는 제거
- 새 역할 생성

### 권한 이해하기

각 역할은 사용자가 해당 역할로 수행할 수 있는 작업을 결정하는 모듈 권한 집합을 가지고 있습니다. 권한은 모듈별로 조직되며, 생성, 읽기, 업데이트, 삭제, 승인, 거부, 내보내기, 가져오기 및 인쇄와 같은 작업을 포함합니다.

### 감사 로그 보기

감사 로그 테이블은 다음 정보와 함께 기록된 모든 작업을 표시합니다:

- **작업** — 수행된 작업 유형
- **엔터티** — 영향을 받은 엔터티 유형(사용자, 역할, 권한 등)
- **사용자** — 작업을 수행한 사람
- **타임스탬프** — 작업이 발생한 시각

### 감사 로그 필터링

검색바와 필터를 사용하여 특정 감사 항목을 찾습니다. 작업 유형, 엔터티 유형, 사용자 및 날짜 범위로 필터링할 수 있습니다.

## 권한 요구 사항

관리 패널과 섹션 접근은 적절한 관리 권한이 필요합니다:

- **관리자 대시보드** — 관리 역할 필요
- **사용자** — 사용자 관리 권한 필요
- **��할** — 역할 관리 권한 필요
- **감사 로그** — 감사 로그 읽기 권한 필요
- **시스템 공지사항** — 시스템 공지사항 관리 권한 필요
- **부문** — 시스템 관리자 접근 필요

필요한 권한이 없으면 해당 섹션에 접근할 수 없습니다.
