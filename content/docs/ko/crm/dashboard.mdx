## 대시보드 헤더

대시보드 상단에는 인사말과 페이지 제목이 표시됩니다. 오른쪽 상단의 **새로 고침** 버튼은 모든 위젯 데이터를 새로 로드합니다. 타임스탬프는 데이터가 마지막으로 업데이트된 시각을 표시합니다.

## 영업 워크플로우

영업 워크플로우 위젯은 영업 파이프라인의 주요 개요입니다. 네 가지 핵심 지표와 막대 차트를 표시합니다.

### 지표 타일

네 개의 클릭 가능한 타일은 각 영업 단계의 현재 수를 보여줍니다:

| 타일 | 설명 |
|---|---|
| **리드** | 시스템의 활성 리드 수 |
| **잠재고객** | 자격 있는 잠재고객 수 |
| **기회** | 파이프라인의 거래 수 |
| **계정** | 관리되는 계정 수 |

어떤 타일이라도 클릭하여 해당 섹션으로 직접 이동합니다. 위젯 헤더의 **새 기회** 버튼은 기회 생성 폼을 엽니다.

### 모듈별 기록 차트

위젯 오른쪽의 막대 차트는 영업 모듈 간 기록 분포를 보여줍니다. 활동을 어디에 집중시키고 있는지 이해하는 데 도움이 됩니다.

### 바닥글 링크

위젯 하단의 **영업 작업 공간 열기**를 클릭하여 리드 페이지로 이동합니다.

## 주식

주식 위젯은 CRM 대시보드에서 바로 시장 요약을 제공합니다:

- 위젯 상단의 **검색 상자를** 사용하여 이름이나 코드로 주식을 찾고 선택합니다
- 위젯은 현재 가격, 가격 변동 및 가격 이력을 보여주는 차트를 표시합니다
- **시간 범위 선택기**를 사용하여 다른 기간을 봅니다 (1D, 5D, 1M, 3M, 1Y)
- **주식 열기**를 클릭하여 완전한 주식 관리 인터페이스를 엽니다

표시되는 요소:

- 주식 식별자 및 이름(검색을 통해 선택됨)
- 인도네시아 루피아 단위의 현재 가격
- 색상에 따라 코드된 가격 변동(절대값 및 백분율, 상승은 녹색, 하락은 빨간색)
- 이전 마감 가격
- 날짜와 가격을 보여주는 대화형 툴팁이 있는 가격 차트

## 순위

순위 위젯은 포트폴리오 및 거래 성과에 대한 요약 순위 뷰를 제공합니다:

- 위젯 헤더의 선택기를 사용하여 **P/L 순위**와 **거래 순위** 간 전환합니다
- 각 순위 유형마다 상위 5개 ��목이 표시됩니다

### P/L 순위 열

| 열 | 설명 |
|---|---|
| 순위 | 순위에서의 위치 |
| 주식 | 주식 코드 및 이름 |
| 평균 가격 | 평균 거래 가격 |
| 종가 | 최신 마감 가격 |
| 일일 P/L 금액 | 당일 이익 또는 손실 |
| 주식 가치 | 총 시장 가치 |
| 총 잔액 | 계정 잔액 |
| P/L 비율 | 백분율 수익률(색상 코드) |

### 거래 순위 열

| 열 | 설명 |
|---|---|
| 순위 | 순위에서의 위치 |
| 주식 | 주식 코드 및 이름 |
| 시가 | 기간의 시작 가격 |
| 종가 | 기간의 마감 가격 |
| 가격 변동 | 절대 가격 변동 |
| 총 수량 | 거래된 주식 수 |
| 총 가치 | 총 거래 가치 |
| 총 거래량 | 거래량 |
| 변동률 % | 백분율 변동(색상 코드) |

**P/L 순위 모두 보기** 또는 **거래 순위 모두 보기**를 클릭하여 트렌드 캐치 섹션에서 완전한 순위를 엽니다.
