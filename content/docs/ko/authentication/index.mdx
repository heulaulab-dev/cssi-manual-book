# 인증

인증은 CSSI 애플리케이션 에코시스템을 위한 공유 로그인 환경을 제공합니다. 사용자는 Portal에 진입하고 사용할 수 있는 애플리케이션에 접근하기 전에 인증해야 합니다.

## 인증 작동 방식

**기존 사용자:**

```
로그인 → Portal
```

**최초 사용자:**

```
기본 비밀번호로 로그인
→ 비밀번호 변경
→ 다시 로그인
→ Portal
```

**비밀번호 분실:**

```
비밀번호 찾기
→ 이메일 OTP
→ 새 비밀번호 설정
→ 다시 로그인
→ Portal
```
