# 비밀번호 찾기

비밀번호를 기억하지 못하는 경우, 비밀번호 찾기 흐름을 통해 등록된 이메일로 신원을 확인하고 새 비밀번호를 생성할 수 있습니다.

### 단계 6 - 다시 로그인

로그인으로 돌아가 사원 ID와 새 비밀번호로 인증합니다.

성공적으로 인증되면 Portal에 진입합니다.

  </Step>
</Steps>

## 비밀번호 찾기 흐름 요약

```
비밀번호 찾기
→ 이메일 OTP
→ 새 비밀번호 설정
→ 다시 로그인
→ Portal
```

로그인 완료 후 [Portal 문서](/docs/portal)를 참조하세요.
