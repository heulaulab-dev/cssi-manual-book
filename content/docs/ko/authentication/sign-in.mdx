  <Step>

### 단계 2 - 사원 ID 입력

계정에 할당된 사원 ID를 입력합니다.

  </Step>
  <Step>

### 단계 3 - 비밀번호 입력

기존 사용자는 현재 비밀번호를 입력합니다. 최초 사용자는 계정에 제공된 기본 비밀번호를 입력합니다.

<Callout type="info">
  처음 로그인하는 경우, CSSI는 계속 진행하기 전에 새 비밀번호를 생성하도록 요구합니다. [첫 로그인 비밀번호 변경](./first-time-password)을 참조하세요.
</Callout>

  </Step>
  <Step>

### 단계 4 - 로그인

인증이 성공하면:

기존 사용자는 Portal로 이동됩니다. 최초 사용자는 비밀번호 변경 흐름으로 이동됩니다.

  </Step>
</Steps>

## 로그인 후

**기존 사용자:**

```
로그인 → Portal
```

**최초 사용자:**

```
로그인 → 비밀번호 변경 → 다시 로그인 → Portal
```

도착한 후의 내용은 [Portal 문서](/docs/portal)를 참조하세요.
