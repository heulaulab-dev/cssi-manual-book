# 첫 로그인 비밀번호 변경

기본 비밀번호로 처음 로그인할 때, CSSI는 계속 진행하기 전에 새 비밀번호를 생성하도록 요구합니다. 이는 필수 흐름입니다.

## 비밀번호 변경

<Steps>
  <Step>

### 단계 1 - 기본 비밀번호로 로그인

사원 ID와 계정에 제공된 기본 비밀번호를 사용하여 로그인합니다.

자세한 내용은 [로그인](./sign-in)을 참조하세요.

  </Step>
  <Step>

### 단계 2 - 새 비밀번호 생성

CSSI는 비밀번호 변경 화면을 표시합니다. 새 비밀번호를 입력합니다.

  </Step>
  <Step>

### 단계 3 - 새 비밀번호 확인

새 비밀번호를 다시 입력하여 확인합니다.

  </Step>
  <Step>

### 단계 4 - 비밀번호 변경 완료

새 비밀번호가 성공적으로 저장되면, 다시 로그인해야 합니다. 자동으로 계속 진행되지 않습니다.

<Callout type="warning">
  비밀번호를 변경해도 기존 로그인이 자동으로 계속되지 않습니다.
  새 비밀번호를 사용하여 다시 로그인하세요.
</Callout>

  </Step>
  <Step>

### 단계 5 - 다시 로그인

로그인 페이지로 돌아가 동일한 사원 ID와 새 비밀번호로 인증합니다.

성공적으로 로그인하면 Portal로 이동됩니다.

  </Step>
</Steps>

## 첫 로그인 흐름 요약

```
기본 비밀번호
→ 비밀번호 변경
→ 다시 로그인
→ Portal
```

로그인 완료 후 [Portal 문서](/docs/portal)를 참조하세요.
